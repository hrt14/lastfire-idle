# ワーキングプラネット ― 放置ゲームのシリーズ

働いて街と星を大きくしていく、スマホ向けWebゲームのシリーズです。
公開先は `working-planet.hitobito.jp`。**はんじょうダッシュ**（ラーメン一直線／
ドリームパーク／湯けむり温泉街）と、原始時代からはじまる **ワーキングプラネット**
（火のはじまり／大河の文明／文字のはじまり）が遊べます。

- **湯けむり温泉街** — 道の上の足湯ひとつから、道を延ばし、店を建てて温泉街へ（30区画）。
  仕様と実装メモは [docs/onsen-town.md](docs/onsen-town.md)
- **世界水族館** — メダカ数匹の小さな水槽から、世界の大海、ショップとレストラン、
  そして時代をさかのぼって40億年前の生命誕生の海まで（54区画）。
  館内グラフィックのメモは [docs/aquarium-hall-v5.md](docs/aquarium-hall-v5.md)、
  施設棟と古代棟は [docs/aquarium-expansion-v6.md](docs/aquarium-expansion-v6.md)
- **火のはじまり** — 狩り・薪・たき火から、集落と村へ（6区画）。
  設計メモは [docs/fire-early-game.md](docs/fire-early-game.md) と
  [docs/fire-zones.md](docs/fire-zones.md)
- **大河の文明** — 川の水を畑へ運ぶところから、水路・土器・牧畜・市場・町へ（6区画）。
  仕様と実装メモは [docs/taiga-civilization.md](docs/taiga-civilization.md)
- **文字のはじまり** — 数えられない倉から、粘土板・書記・記録の館・法典碑へ（6区画）。
  仕様と実装メモは [docs/moji-writing.md](docs/moji-writing.md)

## 公開の設定

### ドメイン
1. Vercel のプロジェクト → Settings → Domains に `working-planet.hitobito.jp` を追加
   （<https://vercel.com/dashboard> → lastfire-idle → Settings → Domains）
2. `hitobito.jp` の DNS に **CNAME `working-planet` → `cname.vercel-dns.com`** を足す
   - Vercel で DNS を持っている場合: <https://vercel.com/dashboard/domains>
   - Cloudflare の場合: <https://dash.cloudflare.com/> （プロキシは切って DNS only に）
3. 証明書が発行されるまで数分待つ（Vercel の画面が Valid になれば完了）

### Google ログインとクラウドセーブ（Firebase）
未設定でも遊べます。その場合は記録がブラウザのなかだけに残ります。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作る
2. **Authentication → Sign-in method → Google** を有効にする
   <https://console.firebase.google.com/project/_/authentication/providers>
3. **Authentication → Settings → 承認済みドメイン** に
   `working-planet.hitobito.jp` と Vercel のプレビュー用ドメインを足す
   <https://console.firebase.google.com/project/_/authentication/settings>
4. **Firestore Database** を作る（本番モード）。ルールはこれだけでよい:
   <https://console.firebase.google.com/project/_/firestore/rules>

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /saves/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

5. ウェブの設定値（firebaseConfig）は `lib/firebase.ts` に直接書いてある。
   ブラウザに配られる公開値で秘密ではないため、環境変数にはしていない。
   別のプロジェクトに向けたいときは、このファイルの値を書き替える
6. **スマホのログイン対策**: `working-planet.hitobito.jp` では、認証の受け口を
   同じドメインに置いている（`next.config.ts` の中継 + `authDomain` の差し替え）。
   これに合わせて、Google Cloud の OAuth クライアントに次を登録しておくこと:
   <https://console.cloud.google.com/apis/credentials?project=working-planet>
   - 承認済みの JavaScript 生成元: `https://working-planet.hitobito.jp`
   - 承認済みのリダイレクト URI: `https://working-planet.hitobito.jp/__/auth/handler`

セーブは `saves/{uid}` に丸ごと1件で入ります。ログインすると、端末とクラウドの
**新しい方**を正として合わせ、そのあとは保存のたびに数秒おきに送ります。

## はんじょうダッシュ

『ホワイトアウトサバイバル』の広告で見かけるタイプ ——
**アーケードアイドル（arcade idle / ハイブリッドカジュアル）** のスマホ向けWebゲームです。
『ピザレディ』『ザ・パーフェクトホテル』『オフィスマスター』『スージーの美食帝国』と
同じ型で、店主を直接動かしてラーメンを運び、店を広げ、店員を雇って自動化していきます。

ブラウザだけで動きます。記録は端末の `localStorage` に保存され、
Google でログインするとアカウントにも保存されます（別の端末でも続きから遊べます）。

## 中核のループ

1. **画面をスワイプして店主を動かす**（PCは矢印キー／WASD）
2. 厨房の寸胴にできあがった**丼を拾う**。頭の上に積み上がる（運べる数は強化で増える）
3. 席で**待っているお客さんに近づくと、自動で出す**
4. 食べ終わったお客さんが**カウンターにお金を置く**。踏むと回収
5. 緑の枠に**立つとお金が吸い出され**、席・寸胴・店員・強化が手に入る
6. **ホール店員や配膳ロボを雇うと 2〜4 を自動でやってくれる** ＝ ここが「放置」

拾う・運ぶ・出す・踏むはすべて**近づくだけで自動**。ボタンは強化メニューだけです。

## 中身

買い物はすべて店内の緑の枠で行います。**メニュー画面はありません。**

- **店の拡張**: 店は4区画。工事中の柵の手前の枠を買うと**店そのものが広がる**。
  下（テーブル席）にも右（製麺所）にも増築でき、その先に宴会場がある。
  広がったぶんは画面が店主を追って縦横にスクロールする
- **店の外**: 入口を出ると歩道と車道がある。お客さんはこの通りから歩いてくる。
  街灯の下に**券売機**と**呼び込み看板**を置ける。店を広げると店先も前へ出る
- **設備**: 厨房側は製麺機（全寸胴 +30%）と大型冷蔵庫（置ける数 +4）。
  店の外は券売機（お金が自動で入り、レジ係はホール店員へ配置転換）と
  呼び込み看板（客が1.5倍のペースで来る）。設備ごとに見た目が違う
- **席と寸胴**: 寸胴5台／カウンター席4・テーブル席3・座敷席4
- **店員**: ホール店員4人（自分の代わりに運ぶ）、配膳ロボ3台（速くたくさん運ぶ）、
  レジ係2人（集金を自動化）、調理人5人（担当の寸胴が2.2倍速）、板前（全寸胴が1.4倍速）
- **強化**: 厨房の中に4つの枠が並ぶ。両手鍋（積載）／厨房シューズ（速度）／
  業務用寸胴（調理速度）／看板メニュー（単価）。何度でも強化でき、そのたびに値上がりする
- **長押しで説明**: 枠・寸胴・席・店員・お客さん・自分、どれでも長押しすると
  効果と値段が出る。強化枠は「いま」と「次のレベル」を並べて表示する
- **投資先への緑の点線**: 自分から、いま投資できるいちばん近い枠へ緑の点線が伸びる。
  払い切れる枠があればそこへ、まだ足りないうちは薄い線でいちばん近い枠へ。
  枠が画面の外にあるときは、画面のへりに緑の矢印と「名前・残りの値段」が出る。
  ステージが広がっても、次にお金を入れる先を見失わない
  （橙の点線は「いまやる仕事」、緑の点線は「投資できる枠」で色を分けている）
- **効果音**: 小銭を拾うと「チャリン」、丼を置くと「コトッ」、買えると小さなジングル。
  WebAudioで生成しているので音声ファイルは持たない（右上でミュート切替）
- **放置収入**: 運ぶ人が1人でもいれば、閉じているあいだも最大8時間ぶん稼ぐ。
  「調理の速さ・席数・運ぶ人数」のいちばん細いところが取り分を決める
- お客さんは席が空いていれば入口から入ってきて、自分の席まで歩き、食べて、帰る

序盤は数往復で必ず何か買えるように価格を置いています（強化50円〜、寸胴150円、
ホール店員280円）。

### 湯けむり温泉街（第3ステージ）

ドリームパークの10区画をぜんぶ開けると解禁されます。
このステージだけ **店の中ではなく道からはじまります**。

- 最初にあるのは、山あいの道・こわれかけの足湯・手ぬぐいの箱だけ
- 道ぞいに店を建て、道を延ばし、また店を建てて、30区画の温泉街にしていく
- 建物は買うと外側（壁・戸口）だけが建ち、**中の設備と店員は一つずつ買っていく**
- 店員は担当の店から出ない。客も店員も**道づたいにしか歩けない**ので、
  道をつなぐこと自体が効率化になる（石畳を敷くと足が速くなる）
- 湯・料理・甘味とみやげの3系統。足湯／共同浴場／露天風呂、そば・串焼き・炉端、
  蒸しまんじゅう・プリン・夜パフェ、湯宿と大旅館まで
- **町に一日がある**（10分でひとめぐり）。夜は夜見世通りが2倍、昼は食べ歩きが強い。
  晴れ・曇り・小雪が変わり、小雪の日は露天が人気になるかわりに道の足がにぶる
- **源泉の湯量にかぎりがある。** 湯を使う施設を増やしすぎるとぬるくなるので、
  そのたびに源泉を掘り増していく
- 大浴場まで建てて灯籠を入れると、毎晩 **湯あかり大祭**。人出が3倍になり、
  評判80%以上で越えると町が完成する

草津温泉のかたちをモチーフにしていますが、地名・実在の店や施設の名前は使っていません
（[docs/onsen-town.md](docs/onsen-town.md) §2）。

### 文字のはじまり（ワーキングプラネット 第3ステージ）

「大河の文明」で街が育ちきったあとの話です。
生産はもう足りていて、足りないのは**いくつあるか分かること**。

- 開始画面にあるのは、麦畑・麦袋のあふれた倉・住民の食卓だけ。
  最初に買うのは畑ではなく**数え場**（ござに粘土を置いただけの場所）
- 川辺の粘土 → 練り場 → 乾燥棚 → 書記小屋、と**粘土板を作る流れ**が立ちあがる。
  書けた板は街の「記録」として積みあがっていく
- 記録がたまると文字が一段すすむ。**「文字Lv.4」ではなく
  「畑の境目を、書き残せるようになった」**と、意味のことばで出る
- 街が大きくなるほど**混乱**が増える。「いくつ？」「また運ぶの？」
  「ここは誰の畑？」と、その場の人の頭の上に吹き出しが出る。
  書記を増やし、記録庫を建て、文字を進めると静かになる
- 段階が上がるたびに街の見た目が変わる。倉の麦袋が列に積まれ、袋に札が下がり、
  数え場が屋根付きの作業所になり、街じゅうに刻みと立て札と境界石が増えていく
- 最後は**大法典碑**。石板・記録板・契約板・徴税記録をぜんぶ運びこむと、
  ほかの建物の2倍以上の高さで立ち、人が集まってくる

情報も物資と同じ「持って運ぶ荷」にしてあるので、
終盤は麦袋と粘土板が同じ道を同時に流れます。

## 技術メモ

- Next.js 16（App Router）／React 19／TypeScript、ゲームエンジンなし・依存は最小限
- ゲーム本体は `<canvas>` に毎フレーム描画。画像アセットは一枚も使わず、
  床・のれん・寸胴・湯気・人・丼・小銭まですべて Canvas 2D の図形で描いている
- シミュレーション（`lib/shop.ts`）は描画から完全に独立した純粋なロジック。
  `update(state, input, dt)` を実時間の差分で回すだけなので、フレームレートに依存しない
- Reactは HUD とシートだけを担当。ゲーム状態はReactの外に置き、
  約110msごとにサンプリングして渡すので、60fpsの描画が再レンダリングに巻き込まれない
- 入力はフローティングジョイスティック（画面のどこを触っても出る）＋キーボード
- セーブは5秒ごと＋タブを閉じる/隠すタイミング。壊れたセーブは `fromPersisted` で復旧

```
app/         画面の外側（HUD・強化シート・遊びかた・放置報酬モーダル）
components/  ゲーム本体（Shop.tsx: キャンバス描画・入力・ゲームループ）
lib/         shop.ts（シミュレーション）・shopStore.ts（保存）
             sfx.ts（WebAudioの効果音）・format.ts（数値整形）
```

```bash
npm install
npm run dev      # http://localhost:3000
```

```bash
npm run lint
npm run build
```

## デプロイ

Vercelにこのリポジトリをインポートすると、Next.jsとして自動検出されます。
環境変数は不要です。スマホのホーム画面に追加するとフルスクリーンで遊べます。
