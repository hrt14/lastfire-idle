# ラストファイア ― 雪原拠点経営

『ホワイトアウトサバイバル』の広告で見かけるような、**放置系・経営シミュレーション**の
スマホ向けWebゲームです。焚き火をかき立てて資源を集め、建物を強化し、吹雪をやり過ごしながら
雪原の拠点を大きくしていきます。

ブラウザだけで動き、サーバーもアカウントも不要です。記録は端末の `localStorage` に保存されます。

## ゲームの流れ

1. **焚き火をタップ**して木材と石炭を集める（タップで「暖」が上がり、全生産が最大 +80％）
2. 集めた資源で**建物を建設・強化**する
3. 建物が育つと、**アプリを閉じているあいだも資源が貯まる**（最大8時間＋見張り台のレベル、効率60％）
4. 建物の合計レベルが8を超えると**吹雪**が来る。石炭を切らすと生存者が凍える
5. 合計レベル120で**移住**が解禁。拠点を捨てて「残り火」を得ると、以降の全生産が永続で強化される

## 主な仕組み

- **資源**: 木材・食料・石炭・鋼材の4種類
- **建物**: 焚き火／木こり小屋／狩猟小屋／炭鉱／避難所／食堂／製鉄所／工房／見張り台の9種類
  - コストはレベルごとに 1.15〜1.24 倍で増加、`×1 / ×10 / MAX` のまとめ買いに対応
  - 合計レベルに応じて段階的に解禁
- **生存者**: 避難所で上限が増え、食料を消費しながら自動で集まる。人数がそのまま労働力ボーナスになる
- **暖（ヒート）**: タップで上昇し時間で減衰。高いほど全生産が上がる、能動プレイのご褒美
- **吹雪**: 一定間隔で発生し、拠点の規模に比例して石炭を消耗する。
  焚き火と見張り台で消耗を軽減。石炭が尽きると生産が40％まで落ち、生存者が減る
- **目標（クエスト）**: 15種類。達成すると資源報酬を受け取れる
- **移住（プレステージ）**: 残り火1つにつき全生産 +15％

## 技術メモ

- Next.js 16（App Router）／React 19／TypeScript、依存は最小限
- ゲーム状態は React の外（`lib/store.ts`）に置き、`useSyncExternalStore` で購読。
  100msごとのティックで実時間の差分を進めるため、タブが重くても進行がずれにくい
- 離席中の進行は「保存時刻との差分」から復帰時にまとめて計算（`applyOffline`）
- セーブは5秒ごと＋タブを閉じる/隠すタイミング。壊れたセーブは `normalizeState` で復旧
- 描画はCSSとインラインSVGのみ。画像アセットなし

```
app/       画面（1ページ）とスタイル
data/      建物とクエストの定義
lib/       ゲームロジック（game.ts）・状態管理（store.ts）・数値整形（format.ts）
```

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
```

品質確認:

```bash
npm run lint
npm run build
```

## デプロイ

Vercelにこのリポジトリをインポートすると、Next.jsとして自動検出されます。
環境変数は不要です。スマホのホーム画面に追加するとフルスクリーンで遊べます。
