# 「火のはじまり」序盤の設計メモ

仕様書「火のはじまり 序盤再設計 v0.1」を実装したときの、
決めごとと、実際に測った数字を残しておく。

## 工程

```
草原 ──(生肉)──────────────────┐
                                ├─▶ たき火（薪で焼く）──(焼き肉)──▶ ベンチの仲間
森 ──(丸太)──▶ 薪割り場 ──(薪)─┘
```

- 草原と森は「取りに行く場所」。近づくと狩れる／切れる。
- 薪割り場は **人の手が要る**（`StoveSpec.manual`）。薪割りを雇うまでは、
  プレイヤーがそばに立っているあいだだけ進む。ここが「丸太を薪に変える」
  必須工程であって、単なる速度上昇役ではない。
- たき火は生肉1こと薪1こを消費して焼き肉1こを作る。基本 4.0秒、
  火の番が付くと 2.0秒。

## 順ぐりに出す枠

`revealLimit: 2` で、まだ買っていない買い切りの枠を同時に2つまでしか出さない。
出す順番は各データの `reveal`。一度出した枠は、買うまで引っこめない
（`ShopState.revealed` に残して保存する）。強化の枠は買っても消えないので、
この2つの枠数には数えない。

狩人の枠だけは `needServed: 5` で、5食提供するまで出てこない。
それまでは、狩り・伐採・薪割り・投入・提供・集金のすべてを自分でやる。

## 価格

仕様書の価格表は「初期単価8貝を前提とした仮値」で、
**プレイテストで調整する**前提だった。そのまま入れると、
1区画目の完全自動化までが 20分以上かかり、
購入と購入のあいだも 150〜200秒あいてしまう
（仕様書 §12.1 の「6〜10分」「30〜90秒」に届かない）。

そこで、案内どおりに動く自動プレイヤーで素振りしながら、
仕様書が**必須としている時間のほうに**価格を合わせた。

| 段階 | もの | 仕様書の仮価格 | 実装 |
|---|---|---:|---:|
| 1 | 狩人 | 40貝 | 40貝 |
| 2 | 木こり | 64貝 | 28貝 |
| 3 | 薪割り | 80貝 | 48貝 |
| 4 | はこび手1人目 | 96貝 | 64貝 |
| 5 | 2席目 / 編みかご | 120 / 80貝 | 76 / 56貝 |
| 6 | はこび手2人目 | 160貝 | 96貝 |
| 6.5 | 3席目（追加） | ― | 90貝 |
| 7 | 火の番 | 200貝 | 120貝 |
| 8 | 拾い手 | 280貝 | 140貝 |
| 9 | わらじ | 160貝 | 110貝 |
| 10 | 犬ぞり | 800貝 | 320貝 |

**3席目を火の番の前に足した**のは、仕様書 §6.3 の
「下流の席不足で効果が消える場合は、先に席を解放する」に従ったため。
2席のままだと火の番を雇っても提供数が +30〜37% しか増えず、
§12.4 の「+40%以上」に届かなかった。3席にすると +43〜50% になる。

## 測った数字（30分の素振り・3回平均）

| 項目 | 実測 | 仕様書の目標 |
|---|---:|---|
| 初回提供まで | 13〜15秒 | 30秒程度 |
| 5回提供まで | 68〜76秒 | ― |
| 最初の購入（狩人） | 70〜79秒 = 5食目 | 5〜8食以内 |
| 購入から次の購入まで | 36〜99秒 | 30〜90秒 |
| 基本自動化の完成（拾い手） | 585〜600秒 ≒ 9.8分 | 6〜10分 |
| 火の番の前後2分の提供数 | 30食 → 42〜45食（+40〜50%） | +40%以上 |
| 1人目のはこび手の運搬力 | 2人ぶんの 56〜60% | 55〜70% |
| 荷物を持ったまま5秒以上の停滞 | 0〜1回 / 30分 | 起きないこと |

素振りは案内どおりに一手ずつ動くだけなので、
まとめて積んで回る人間より遅い。実際の値はこれより速いはず。

## 気をつけたところ

- **強化の枠を通り道に置かない。** 強化の枠は買っても消えないので、
  たき火とベンチのあいだのような通り道に置くと、通りかかるたびに
  貝が吸い出されて経済が回らなくなる。草原の西はしに「道具置き場」として
  まとめてある。
- **1人目のはこび手は、わざと運びきれない強さにする。** 積み下ろしの間
  （`HAUL_PAUSE`）と品種ごと3こという上限で、2人ぶんの 6割ほどに収まる。
- **区画は 720 × 520。** 画面には収まらないので `view: 400` で少し引き、
  カメラがプレイヤーを追う。目的地が画面の外にあるときは、
  画面のへりに向きと距離が出る。
