# OCEAN PLANET ゲーム性改善メモ

## お手本から移植する要素

### ドリームパーク
- `currentObjective` が次の目的地を座標で返す
- プレイヤーから目的地へ、動く破線を常時表示
- 目的地を脈動するリングで強調
- 目的地が画面外なら画面端に矢印を表示
- 序盤の購入候補は順番に出し、推奨購入へ誘導

### 火のはじまり
- 資源をボタンで取得せず、フィールド上の対象へ近づいて作業する
- 動く獲物を追い、一定時間近くにいると捕獲が完了する
- 捕獲中は円形の進捗を表示
- 取得後は対象が減り、時間経過で再出現する

## 海の星への適用
- 浅瀬・群島・氷海の魚はフィールド内を泳ぐ
- 魚へ近づき、捕獲ゲージをためて1匹ずつ取得
- 貝・プランクトン・鉱石も、対象物の近くで採集ゲージをためる
- 手持ち、加工状況、完成品、資金に応じて次の目的地を自動判定
- プレイヤーから次の目的地へ破線と脈動リングを表示
- 資金が足りる推奨購入パッドを優先案内
- 仕事の案内（黄）とは別に、いま投資できるいちばん近い枠へ緑の点線を出す。
  大河の文明の `nearestPadTarget` と同じ選びかた（払える枠のうち近いもの →
  どれも払えなければ近い枠へ薄く）で、資源を追っているあいだも投資先を見失わない
- 完全自動化前は重要な自動化設備を先に出し、不要な強化購入で進行が遅れることを防ぐ

## 序盤プレイシミュレーション

実ブラウザ上の指操作はこの検証環境では自動化できないため、移動距離、捕獲時間、加工時間、報酬、購入条件を使って最短進行を再現した。

### 発見した問題

調整前は、効率よく動くと約1分で漂流浅瀬を抜けられた。漁師・加工係・配達いかだを順番に導入する前に進行が終わり、自動化した実感が弱かった。

### 調整

- 最初の依頼報酬160シェルは維持
- 干物台60＋漁師90＝残り10シェルも維持
- 焼き台の処理時間を1.5秒から2.2秒へ変更
- 加工係を150から320シェルへ変更
- 配達いかだを280から650シェルへ変更
- サンゴ礁への出航を650から1,400シェルへ変更
- 次海域を開くまでは能力強化を表示しない

### 状態遷移結果

1. 依頼1回目：160シェル
2. 干物台と漁師を購入：10シェル
3. 依頼3回目で加工係を購入：10シェル
4. 依頼7回目で配達いかだを購入：0シェル
5. 依頼16回目でサンゴ礁へ出航：40シェル

最短操作の概算は約2分15秒。実際には魚を追う移動、迷い、画面確認が入るため、初回プレイは約3〜5分を想定する。

### 詰まり確認

- 最初の報酬で干物台と漁師を連続購入できる
- 購入候補が1件ずつなので、順番を飛ばせない
- 大量のシェルを持つ既存セーブでも、次海域解放前に能力強化へ寄り道できない
- 手持ち素材がある場合は必ず対応設備へガイドされる
- 完成品がある場合は受取地点、受取後は納品地点へガイドされる
- 資金不足時は採集・加工へ戻され、購入パッドに立ち続ける必要がない
