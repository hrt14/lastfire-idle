# 「文字のはじまり」ゲーム仕様書 v0.1

- ステータス：実装ずみ（たたき台からの実装まで）
- 対象：hrt14/lastfire-idle
- シリーズ：ワーキングプラネット
- 前ステージ：「大河の文明」
- ステージ種別：独立した次ステージ
- 一言コンセプト：**物を運ぶ文明から、情報で動く文明へ**

> 「文字を書くこと」ではなく、
> 「記録できない都市」を「記録によって巨大化できる文明」へ変えるゲーム。

## 0. 実装メモ（この仕様をどう作ったか）

ステージ本体は `data/stages.ts` の `moji`、
記録と混乱のしくみは `lib/moji.ts`、街の絵は `components/Shop.tsx` の
`drawCity` / `drawCityGround` / `drawCitySeat`。

### 既存のしくみへの当てはめ

「火のはじまり」「大河の文明」で使っている
採集・加工・運搬・建設・アップグレード・エリア解放をそのまま流用し、
**「情報」という第2の物流を既存ループへ重ねた**。新しいエンジンは作っていない。

| 仕様のことば | 実装 |
|---|---|
| 麦畑・あふれる倉 | 素材の作業場（`item: wheat`）。倉は積みかたが乱雑なぶん遅い |
| 数え場 | 「麦1こ → 数量札1こ」の作業場（`takes: wheat`／`manual`） |
| 練り場 | 「粘土1こ → 生の粘土板1こ」の作業場 |
| 乾燥棚 | 「生板1こ → 乾板1こ」。積める数がそのまま保存能力になる |
| 書記小屋 | 「乾板1こ + 数量札1こ → 記録板1こ」（`takes` + `fuel`） |
| 書記の学校 | 「乾板1こ + 葦1こ → 記録板1こ」。弟子を雇うほど机と人が増える |
| 市場の記録席 | 「記録板1こ + 布1こ → 契約板1こ」 |
| 測量所・徴税所 | 「記録板 + 契約板 → 土地台帳／徴税記録」 |
| 記録庫・大文書庫・行政所 | 建築予定地（`needs` に材料を運びこむと建つ） |
| 大法典碑 | 建築予定地。石板・記録板・契約板・徴税記録がぜんぶ要る |
| 情報物流 | 板も物資と同じ「持って運ぶ品」。運搬人・荷車・建築係が運ぶ（`haulers: true`） |

情報の品を物資と同じ荷として扱ったので、
**終盤は麦袋と粘土板が同じ道を同時に流れる**（§16 AC-08）。

### 記録がたまるしくみ

作業場が1つ作りおえた瞬間に `mojiMade` が呼ばれ、
「書き残した板」だけが街の**記録**として積みあがる。

| 品 | 記録として | なぜ |
|---|---|---|
| 数量札 | +1 | 数を線で残しただけでも、これが最初の記録 |
| 記録板 | +3 | 物と数と人を書き分けている |
| 契約板・土地台帳・徴税記録 | +6 | その場にいない相手や、土地・税にまで効く一枚 |
| 生板・乾板 | 0 | まだ何も書いていない白紙 |

### 文字発展ツリー

記録の総数と、区画の進みの**両方**で上がる。
どちらか片方だけ進めても先へ行けないので、街と文字がいっしょに育つ。

| 段階 | 意味（画面に出る言葉） | ゲーム効果 | 記録 |
|---|---|---|---|
| 0 記録以前 | まだ何も書き残せない | ― | 0 |
| 1 数える印 | 数をそのまま残せるようになった | 作業場 +8% | 6 |
| 2 物の記号 | 麦と羊と壺を、書き分けられるようになった | 集客 1.2倍 | 30 |
| 3 人の名前 | だれの仕事かを、書き残せるようになった | 担当のいる作業場 +15% | 90 |
| 4 土地の記録 | 畑の境目を、書き残せるようになった | 畑・粘土場 +25% | 220 |
| 5 取引の記録 | だれと何をいくつ、を残せるようになった | 単価 1.25倍 | 500 |
| 6 契約 | その場にいない相手とも、約束を交わせる | 集客 1.4倍 | 1,100 |
| 7 法 | だれにでも同じ決まりを、書き残せる | 全体 +20%・単価 1.4倍 | 2,400 |

HUDは「文字Lv.4」ではなく、この**意味のことば**で出す（§13）。

### 混乱

`混乱 = (街が抱える量 − 記録の処理能力) / 街が抱える量`（上限 0.45）。

- 街が抱える量 ＝ 作業場×2 ＋ 受け渡し場 ＋ 人の数
- 処理能力 ＝ 4 ＋ 書記×5 ＋ 記録をしまえる建物×8 ＋ 文字の段階×4

混乱があると作業場が最大 35%、集客が最大 30%鈍る。**止まりはしない。**
22秒に一度ほど、いま働いている人の頭の上に吹き出しが出る。

| 混乱 | 吹き出し | 消える段階 |
|---|---|---|
| 在庫不明 | 「いくつ？」 | 1 数える印 |
| 二重運搬 | 「また運ぶの？」 | 2 物の記号 |
| 納品ミス | 「話がちがう」 | 5 取引の記録 |
| 土地争い | 「ここは誰の畑？」 | 4 土地の記録 |
| 税重複 | 「もう納めた」 | 7 法 |

赤いエラーUIだけにせず、**その場のNPCの上に出す**（§10）。

### 通しでの確認

データの点検（`tools/check-moji.ts`）と、案内どおりに動く自動プレイヤーでの
通し素振り（`tools/play-moji.ts` / `tools/reach-moji.ts`）をして直したもの:

- **区画が永久に開かない条件**を2回踏んだ。
  第2区画の条件が「記録30」なのに、記録板を作れるのは第2区画の中だけだった
  （数量札を記録として数えるようにした）。
  第3区画の条件が、第3区画の中にある書記小屋になっていた
  （第2区画で雇う書記に変えた）。
  同じ形の間違いを二度としないよう、点検に
  「条件が自分より後の区画を指していないか」を足した
- 第1区画の受け渡しが1つしかなく、行列で頭打ちになっていた
  （食卓を最初から2つにし、数え場と倉庫係を先に出した）

自動プレイヤーで同じ時間だけ「大河の文明」も動かして、
進みぐあいがシリーズの中で浮いていないことを確かめている。

## 1. 実装の目的

シリーズ進行：火のはじまり → 大河の文明 → **文字のはじまり**

大河の文明で農耕・灌漑・倉庫・市場・船・都市が成立した結果、
「記憶だけでは管理できない」という問題が生まれる。
数量を表す印 → 物を表す記号 → 人名 → 土地記録 → 取引記録 → 契約 → 法、
の順に情報管理能力を獲得する。

完成時は、開始時の「人が多いのに混乱する街」から、
終盤の「物資と情報が同時に流れ、書記・市場・記録館・行政・法典が連動する都市」へ変化する。
UIを隠したスクリーンショットだけでも進行段階が分かること。

## 2. 絶対原則

- 名前が違えば見た目も違わせる。
- 投資したら必ず画面を変える。原則2要素以上の視覚変化を入れる。
- 主役は「文字」と「書記」。大きく、見やすく、繰り返し登場させる。
- 成長 = 画面変化。数字だけで成長を表現しない。
- 前景・プレイ層・後景の3層以上を作る。
- 一本道・完全グリッドを避け、路地・広場・工房街・市場・行政地区に空間リズムを持たせる。
- 最大の成長軸は「街中の文字の総量が増えること」。

## 3. コアゲームループ

1. 麦、羊、油、布、粘土等を生産。
2. 運搬人が倉庫・市場・工房へ運ぶ。
3. 倉庫係・書記が数量や種類を確認。
4. 書記が粘土板へ記録。
5. 記録済み板を記録庫・行政施設へ運ぶ。
6. 在庫・担当・土地・交易・徴税管理が解放。
7. 都市が拡大し人口・物流量が増える。
8. さらに高度な文字・記録技術が必要になる。

独自リソース「記録」は単純ゲージにしない。
段階ごとに街・人物・設備・解放機能が変わる。
UIアイコンは紙ではなく粘土板。

## 4. 文字発展ツリー

§0 の表のとおり実装した。必須ビジュアルの対応:

| 段階 | 必須ビジュアル | 実装 |
|---|---|---|
| 0 | 文字なし、混乱 | 倉の麦袋が転がったまま。吹き出しが頻発 |
| 1 | 数量札、刻み | 袋ひとつずつに札が下がり、袋が列に積まれる |
| 2 | 象形的記号入り板 | 袋の色が種類ごとに分かれる。街の刻みが増える |
| 3 | 個人印、名簿 | 倉の戸口に担当の名札。数え場が屋根付きの作業所になる |
| 4 | 境界石、測量係 | 街に境界石が増える |
| 5 | 価格板、商品札、記録席 | 市場の記録席・商品札 |
| 6 | 契約板、遠方商人 | 契約席と封印つきの板 |
| 7 | 大法典碑 | 建物2つぶんの高さの碑 |

## 5. マップ構成

川 → 農地 → 倉庫街 → 粘土板工房 → 書記学校 → 商人の広場 → 記録の館 →
行政地区 → 法の広場。

| 区画 | 名称 | 中身 |
|---|---|---|
| 第1区画 | あふれる倉 | 麦畑・あふれる倉・数え場・葦の茂み・住民の食卓・倉の帳場 |
| 第2区画 | 粘土板の工房 | 粘土穴・練り場・乾燥棚・書記小屋・木立・材木場・記録庫 |
| 第3区画 | 書記の学校 | 筆の葦原・書記の学校・書記小屋×2・大乾燥棚・校舎・中庭の大校舎 |
| 第4区画 | 商人の広場 | 羊の囲い・織り場・油の木立・市場の記録席・大型市場 |
| 第5区画 | 記録の館 | 測量所・徴税所・館の粘土/練り/乾燥・大文書庫・行政所 |
| 第6区画 | 法の広場 | 採石場・石工の作業場・法文の書記・石畳の広場・大法典碑 |

第1区画の最初の課題は「麦を集める」ではなく
**「麦を数えられるようにする」**。開始画面には畑・倉・食卓しか無く、
最初に出る枠が数え場と倉庫係になる。

数え場は、ござ＋粘土 → 木机 → 屋根付き作業所と、文字の段階で姿が変わる。

## 6. 大法典碑

石板24・記録板20・契約板12・徴税記録8 を運びこむと建つ。
石だけでも文字だけでも建たない ―― 両方の物流がそろってはじめて立つ。

ほかの設備と同じ大きさにしない。**建物2つぶんの高さ**で立て、
面いちめんに法文を刻み、見上げる群衆を足もとに置いて大きさを分からせる。

クリア演出：「人類は、記憶を文明に残せるようになった。」

## 7. ビジュアル方針

古代メソポタミア等の初期都市文明を連想させるが、
完全再現より「一目で古代文明」を優先。
日干しレンガ、土壁、葦、木、壺、布、川、段状建築。

**「全部茶色」は禁止。** 水（青緑）・葦と樹（緑）・布と天幕（朱）・
役人（藍）・石（灰）・粘土板（明るいベージュ）で色差を作る。

3層:

- 前景：葦、壺、積み荷、柱（`drawCityGround` の前景）
- プレイ層：プレイヤー、作業員、書記、工房、市場、物流
- 後景：川、対岸の家、神殿、船、煙、遠くの人

道路・高低差:

- 完全グリッド禁止。大通りはゆるく蛇行させ、路地を2本ぶら下げ、
  途中に小広場のふくらみを置く
- 高低差：川岸 → 堤防 → 市街地 → 行政/神殿の高台

## 8. 職業

農民、運搬人、倉庫係、粘土職人、練り手、乾かし手、**書記**、書記の師匠、弟子、
商人、市場の書記、測量係、役人、衛兵、石工、彫刻師、木こり、材木の係、
羊飼い、織り手、油の摘み手、建築係。

書記はエンジンに専用の職（`scribe`）として足した。
生成りの亜麻の衣、胸に抱えた粘土板、耳にはさんだ尖筆で、
歩いていても書記だと分かる。役人（`officer`／藍と杖）、
石工（`carver`／のみと槌）も同じく専用のすがたを持つ。

作業場の中では `板を取る → 対象を見る → 書く → 持って移動 → 棚へ置く` を回し、
尖筆を小刻みに動かす。

## 9. 物資物流と情報物流

- 物資：麦、羊毛、布、油、葦、粘土、丸太、薪、石、石板
- 情報：数量札、生の粘土板、乾いた粘土板、記録板、契約板、土地台帳、徴税記録

終盤は両方が同時に都市内を流れている。

## 10. 混乱システム

§0 の表のとおり。文字技術の発展で頻度が減り、段階を越えると種類ごと消える。

## 11. アップグレード

すべての強化で、形・色・サイズ・数・配置・装飾・人物・アニメーションのうち
最低1つ、原則2つ以上を変更する。`Lv.数字だけ` は無い。

例：乾燥棚に日よけの葦すだれを買うと、棚の上にすだれが架かり、
積める板が増えて棚の埋まりかたが変わる。

## 12. プレイヤー選択肢

進行中は5〜9個の購入候補を維持する（`revealLimit: 5`、区画が進むと9まで）。
生産増加・記録速度・保存容量・混乱低減・新機能解放が混ざるようにしている。

## 13. UI

- 上部：お金（印）・提供した数・記録（粘土板のしるし）
- 📖 のボタンから「文字と記録」のシート。段階を**意味のことば**で並べる
- 画面右上に、いまの段階／次の段階までの残り／書記の数と記録の余力／
  街のようす（落ちついている〜手がつけられない）
- アンロック時は街へ即時の見た目変化を起こす

縄、筆記具、商品札、秤。
建築：麦畑、あふれる倉、数え場、粘土穴、練り場、乾燥棚、書記小屋、書記の学校、
校舎、中庭の大校舎、記録庫、大文書庫、行政所、市場の記録席、大型市場、
測量所、徴税所、採石場、石工の作業場、石畳の広場、大法典碑。

## 15. Acceptance Criteria

| | 条件 | どう満たしたか |
|---|---|---|
| AC-01 | 開始30〜60秒で「記録不足が課題」と分かる | 開始画面は畑・あふれる倉・食卓だけ。最初に出る枠が数え場と倉庫係。倉の麦袋は転がったまま |
| AC-02 | 粘土→粘土板→記録→保存のループを視覚的に追える | 粘土穴→練り場→乾燥棚→書記小屋→記録庫が横に並び、板が形と色を変えていく |
| AC-03 | 書記が他職業と区別でき、書く動作を行う | 専用の職 `scribe`。抱えた板と尖筆、机では刻む動き |
| AC-04 | 文字技術解放ごとに街が見た目で変わる | 倉の積みかた・数え場の造り・街じゅうの刻みと立て札と境界石が増える |
| AC-05 | 進行中に5〜10程度の投資候補がある | `revealLimit` 5〜9 |
| AC-06 | 前景・プレイ層・後景がある | `drawCityGround` の3層 |
| AC-07 | 初期・中盤・終盤のスクショをシャッフルしても順番が分かる | 文字の量・建物の高さ・色数がすべて単調に増える |
| AC-08 | 終盤は物資物流と情報物流が同時に動く | 板を物資と同じ荷にして、同じ運搬人が運ぶ |
| AC-09 | 大法典碑が明確なランドマーク | 高さ約210、ほかの建物の2倍以上。群衆つき |
| AC-10 | スマホで主役・目的・次の投資先が認識できる | 既存の緑の点線（次の投資先）と橙の点線（いまの仕事）をそのまま使う |

## 16. 絶対NG（と、その回避）

1. 粘土板工房を置いただけで、文字が街に影響しない
   → 記録が段階を上げ、段階が作業場の速さ・集客・単価・混乱に効く
2. 数字レベルだけで進行する → HUDは意味のことばで出す
3. 文字がUIにしか存在しない → 街の地面・壁・立て札・境界石に増えていく
4. 建物が全部同じ箱 → 24種すべて別の形
5. 一本道・横一列 → 蛇行する大通り＋路地2本＋小広場
6. 書記が普通のNPCと同じ → 専用の職と持ちもの
7. 粘土板が見えない → 板の絵は物資より大きく描く
8. 初期と終盤の街並みが同じ → §15 AC-07
9. 法典碑が通常設備と同サイズ → 2倍以上
10. 古代を全部茶色で表現する → §7 の色差

## 17. 非対象

- 「火のはじまり」「大河の文明」のバランス変更
- スキンの能力仕様変更
- 完全な自由配置型都市建設
- 住民の死亡や飢餓を中心にした高難度管理
- 対人戦
