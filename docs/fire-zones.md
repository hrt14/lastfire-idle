# 「火のはじまり」第2区画以降の設計メモ

仕様書「火のはじまり 第2区画以降の再設計 v0.3」を実装したときの、
決めごとと、実際に測った数字を残しておく。

第1区画は [fire-early-game.md](./fire-early-game.md) のまま。ここはその続き。

## 区画ごとに、新しい問題を出す

同じ生産設備を増やすのではなく、区画ごとに別の困りごとを足す。

| 区画 | テーマ | あたらしく足したもの |
|---|---|---|
| 第2区画 | 集落のはじまり | 昼夜・保存食・備蓄・建築・住居・人口 |
| 第3区画 | マンモスの谷 | 歩く巨獣・集団狩猟・罠・解体・大量輸送 |
| 第4区画 | 冬を越す | 気温・吹雪・保温・防寒着・薪の備蓄 |
| 第5区画 | 村の誕生 | 人口を進行値に・公共設備・職業・道 |
| 第6区画 | 川への道 | 加工木材と縄・造船・探索・交易・出航 |

## マップ

区画は横に一列に並べた。西から東へ旅していく形になる。

```
area-0  はじまりの野     x    0..720   （第1区画・そのまま）
area-1  集落のはじまり   x  720..1620  900 × 760
area-2  マンモスの谷     x 1620..2860  1240 × 760
area-3  冬ごもりの丘     x 2860..3760
area-4  村               x 3760..4660
area-5  川辺             x 4660..5560
```

縦に積むと、いちばん下の「野原」から歩いてくる仲間の道のりが
区画のぶんだけ伸びてしまう。横に並べたうえで、
**仲間はその区画の野から現れて、その区画の野へ帰る**ようにした
（`guestEntry` / `updateCustomers` の leaving）。
どの区画でもベンチまで数秒で着く。

## エンジンに足した仕組み

第2区画以降はデータだけでは書けないので、次の4つを足した。

### 貯蔵庫（`StoveSpec.store`）

受け取るだけで何も作らない作業場。食料庫・薪倉庫・衣装棚。
中身は `state.hold` に入り、**セーブに残る**（`Persisted.stored`）。
帰ってきたら食料庫が空、をやらない。

貯蔵庫には「抱えこみすぎない」上限がある（`storeKeep`）。
建てかけの建物がその品を欲しがっているあいだは、
夜のぶん（＝住民の数、最低4）を確保したら、余りは建築へ回す。
これが無いと、食料番が保存肉を全部 食料庫に入れてしまい、
「あと2こで建つ住居」がいつまでも建たなかった（実際そうなった）。

### 建築予定地（`StoveSpec.needs` / `gives`）

枠を買うと「予定地」が立ち、そこへ材料を運びこむと建物になる。
積んだ数は `state.parts[id]` に品種ごとに残り、セーブにも残る。
建つと `built-<id>` が `unlocked` に入るので、
ほかの枠の `unlockAfter` からふつうに参照できる。

`gives` で効き目を書く。

- `houses` … 定住できる人数 +N
- `warm` … 集落の暖かさ +N（第4区画の寒さをやわらげる）
- `hearth` … 共同たき火。夜に薪を燃やして広場を照らす
- `dock` … 探索に出られるようになる
- `sail` … これが建つと「火のはじまり」が終わる

見た目は、柱 → 壁 → 屋根の順に立ちあがる。
足りない材料は予定地の足もとに `3/6` の形で出る。

### 仮置き場（`StoveSpec.pile`）

解体で出た資源が積まれるだけの場所。狩猟キャンプについてくる
（値段0・`unlockAfter: "mammoth-1"`）。
5つの置き場を別々に買わせると、毛皮置き場を買い忘れた人の解体が
永久に止まる。仕様書の「進行不能になる購入順が存在しない」に反する。

### 進み具合の合図（`MARKS`）

「3頭倒した」「寒い夜を3回越えた」「人口20人」のような、
買い物では表せない条件。満たすと `mark-cold-3` のような印が
`unlocked` に入り、次の区画の枠がそこにぶら下がる。

## 購入候補（仕様書 §2）

`revealLimit` は第1区画のあいだ 2 のまま。
第2区画が開くと `revealLimitBy` で 6〜7 に増える。
強化の枠（編みかご・火をあおぐ・わらじ・石塩）は買っても消えないので、
実際に見えている候補はこれに +4。合わせて 10個までに収まる。

一度に新しく出すのは **2つまで**、次を出すまで10秒あける
（`REVEAL_BURST` / `REVEAL_GAP`）。まとめて7個出ると、
何のための枠なのか分からなくなる。

「おすすめ」は、いまつまっているところから1つだけ選ぶ
（`firePriorityPads` → `recommendedPad`）。
保存肉が足りない → 燻製小屋、仮置き場が満杯 → 犬ぞり、
住むところがない → 住居、というふうに。買わなくても進める。

## 第2区画「集落のはじまり」

工程はこうなる。

```
第1区画の生肉 ─┐
                ├─▶ たき火 ─(焼き肉)─┬─▶ ベンチの仲間（貝がら）
森 ─(丸太)─┬─ 薪割り場 ─(薪)─┘      └─▶ 燻製小屋 ─(保存肉)─▶ 食料庫 ─▶ 夜の食事
            └────────────────────────────▶ 建築予定地（住居・集会所）
```

丸太をぜんぶ薪にすると家が建たない。ぜんぶ建築に回すと火が消える。
第2区画のいちばんの判断はここ。

### 昼夜

昼90秒 / 夕方15秒 / 夜30秒 = 1日135秒（仕様書どおりの仮値）。

- 夜は外の仕事（狩り・伐採・粘土）が止まり、仲間も来ない
- 夕方は外の仕事が6割になる
- 夜のはじめに、住民ひとりにつき保存肉1こを食料庫から食べる

足りなくても誰も死なない。翌日の作業が 0.82倍になり、人口が増えず、
「保存肉が3こ足りなかった。明日は燻製を増やそう」と出るだけ。
越せた夜は 1.15倍で始まり、貝がらのおまけが入り、人が増える。

### 人口

住居を建てると定住できる人数が増え、夜を越すたびに増える
（集会所か共同たき火があると 3人ずつ、なければ 2人ずつ）。
住民はただの数字ではなく、朝は広場に出て、夜は住居へ帰る。

### はこび手の優先順

素振りで「毎晩ひもじいまま」になったので、順番を入れた。

1. 今夜のぶんが足りていない日は、保存肉づくりを何より先に（`night`）
2. 次に、建てかけの建物へ材料を入れる（貯蔵庫にため込むより先）
3. あとは、止まっている工程 → 届ける仕事 → 近いもの

これが無いと、待っている仲間へ焼き肉を配るのが always 勝ってしまい、
燻製小屋にはいつまでも材料が回らなかった。

### クリア条件

集会所が建つと、第3区画の枠が出る（`unlockAfter: "built-build-hall"`）。

## 第3区画「マンモスの谷」

マンモスは設備ではない。草原を歩き、草を食べ、警戒し、突進する。

- **持久力**を先に削る（追い込み）。持久力が残っているあいだは体力が減らない
- 疲れると頭が下がり、白い息が出て、動きが遅くなる
- そこではじめて体力が削れる
- 倒れても消えない。その場に横たわり、解体して運び出す

追い込みの速さは `0.0045 × 人数^0.75 ×（1 + 罠 × 0.25）`、
仕留めは `0.006 × 人数^0.8`。仕様書 §4.7 の目標時間に合わせた。

| 構成 | 仕様書の目標 | 計算上 |
|---|---|---|
| プレイヤー＋狩人2 | 3〜4分 | 約2分50秒 |
| 狩人4〜5 | 1分40秒〜2分20秒 | 約1分50秒 |
| 狩人6〜8＋罠 | 60〜90秒 | 約55秒 |

はね飛ばされた狩人は死なず、5〜10秒 転がってから戻る（`Staff.down`）。

### 解体と大量輸送

1頭から マンモス肉36・毛皮6・牙2・脂8・骨6（合わせて58こ）。
毛皮は皮なめし場・複数の建物・交易の席が奪い合う、数少ない資材のひとつなので、
供給を4→6に上げた（プレイテストで「毛皮だけ詰まる」のが見つかったため）。
解体の進みに合わせて、種類ごとの窓で順に出てくる
（毛皮は25%から、牙は45%から、脂は50%から、骨は70%から）。

仮置き場が満杯になると解体は止まる。ただし
**30秒 待っても運び出されなければ、その品はあきらめる**。
脂や牙は使い道が先の区画にあるので、この逃げ道が無いと
解体が永久に止まり、次のマンモスも来なくなる（素振りで実際に詰まった）。
取りこぼしたことは「置き場がなくて脂を6こ 取りこぼした」と伝える。

### 大宴会

マンモス肉30・薪16・脂4 を大宴会場へ運びこむと第4区画が開く。

## 第4区画「冬を越す」

気温 = 時間帯 + 冬 + 天気 + 集落の暖かさ。

- 昼 +7 / 夕方 +2 / 夜 -3
- 冬 -9、寒い -4、吹雪 -9
- 毛皮の住居・共同たき火（薪があるあいだ）・脂のランプ・防寒着で戻す

0度を下回ると作業が遅くなり（最大 0.55倍）、雪の上は足も遅い。
吹雪のあいだは外の仕事が止まる。誰も死なない。

**寒い夜を3回越えると雪が解けはじめ**（`COLD_NIGHTS`）、第5区画が開く。
冬が明けると気温は戻る。冬をずっと続けると、そのあとの区画が
ずっと雪に埋もれて遅いままになってしまう。

第4区画のベンチは **保存肉**を受け取る。
配れば貝がらになるが、その日の夜のぶんが減る。冬の判断はここ。

## 第5区画「村の誕生」

粘土穴 →（土器工房）→ 土器、骨 →（道具工房）→ 道具。
土器と道具はそのまま村のベンチの品になる。

公共設備（井戸・村の門・見張り台・集会所の拡張）と住居は
すべて建築予定地。道を敷くと、通る人みんなが速くなる（1本 +8%）。

人口が20人になると、探索者が大きな川を見つける（`mark-pop-20`）。
住居をぜんぶ建てると定住できる人数は27人。
（最初は24人にしていたが、下の「毛皮の詰まり」が見つかったので20人に下げた）

### 毛皮の詰まり

プレイテストで、「大きな住居」の建築が `毛皮 1/8` のまま長いこと
止まっている報告があった。お金は十分あるのに、資材だけが集まらない。

原因は2つ重なっていた。

1. **はこび手が、建築より「待たせている先」を優先していた。**
   待っている仲間・客へ渡す仕事は `stalled: true` で最優先（-260）、
   建築予定地への搬入は `tag: "build"` で次点（-240）だった。
   このため、毛皮を待つ皮なめし場（皮なめし場の受け口が空＝
   `stalled: true`）や、交易の席（毛皮がほしい客＝`stalled: true`）が、
   建てかけの住居より先に毛皮を吸い取っていた。
   `state.fire.wants[kind]`（建てかけの建物がまだ欲しがっている量）を見て、
   建築が欲しがっている資材は、加工場・客より建築を優先するようにした。

2. **住居の枠が出る順番が遅すぎた。** 第5区画の「大きな住居」
   （人口上限 +6）は、井戸・村の門・見張り台より後ろの reveal 順に
   置いてあり、他の建物をひととおり買い終わるまで出てこなかった。
   住居が増やせないあいだ、人口はずっと頭打ちのままになる。
   reveal 順を早め、他の建物と並行して住居も進むようにした。

あわせて、毛皮そのものの供給も細かった（1頭から4枚。
複数の建物・皮なめし場・交易の席が同じ4枚を取り合っていた）ので、
1頭6枚に増やし、住居2軒の必要数を 8→5 に下げた。

## 第6区画「川への道」

丸太 → 加工木材・縄、川の瀬 → 魚。

小型いかだ（加工木材6・縄4）が建つと探索に出られる。
見つかるものは順ぐりで、取りこぼしがない（仕様書 §7.5）。

魚のいる淵 → 粘土の岸 → 向こう岸の森 → 石切り場 →
**別の集落**（交易の席が開く）→ 大きな川（大型いかだの枠が出る）→ 麦の育つ平野

大型いかだ（加工木材14・縄8・保存肉12・毛皮6・道具4・土器4）を
建てると出航し、「火のはじまり」が終わる。

### 魚の供給過多

プレイテストで、「魚の受け口（川の瀬）がずっと満杯で、誰も運ばない」
という報告があった。原因は単純な需要不足: 網（`net-1`、獲れ高+6）
まで入れると供給はかなり増えるのに、魚を受け取る「川辺の席」は
2つしかなく、他の席（村の食卓・道具の市・交易の席など）と同じ
くじ引きに参加するぶん、席の数が少ないほど魚の順番はなかなか
回ってこない。「川辺の席」をもう2つ足して、受け止め先を増やした
（`seat-5-f1`・`seat-5-f2`、reveal 118・120）。

## 値段

**すべて仮値。プレイテストで調整する。**
第1区画のときと同じで、仕様書の価格表そのままでは
区画のあいだが空きすぎたので、素振りに合わせて置き直した。

いちばん手を入れたのは第2区画の入口。
第1区画の稼ぎは 1分あたり 170〜500貝ほどなので、
2400貝の区画と、その先の 900〜26000貝の設備では遠すぎた。
第2区画の値段はぜんたいに 4割ほど下げてある。

`area-1`（東に集落をひらく）の `reveal` を 11.6 にして、
第1区画の便利な設備（樋・石おの・物見やぐら。6000〜60000貝）より
**先に**見せるようにした。そうしないと、
「1区画目をぜんぶ便利にしてから東へ」しか選べない。
いまは「いまを楽にするか、東へ広げるか」を選べる。

## まだやっていないこと

仕様書にあって、今回は入れていないもの。

- **狩猟の6段階の演出**（追跡 → 包囲 → 追い込み → 疲労 → 討伐 → 転倒）は、
  持久力・疲労・突進・転倒までは入れたが、
  「役割ごとに前方・側面・後方に散る」までは作りこんでいない。
  いまは人数ぶん、まわりを取り囲むだけ。
- **鮮度**（解体後3分以内で価値120%など）は、経過時間だけ数えていて
  値段には効かせていない。
- **人口の内訳**（子ども・高齢者・休息中・職業別）は数えていない。
  人口はひとつの数字。
- **交易の受け取り**（種・家畜候補など）は、貝がらでの取り引きに置きかえた。
  次のステージ「大河の文明」につなぐところで作りこむ。
- 罠は「追い込みが速くなる」一本の効き目にまとめてある。
  仕様書の罠ごとの効き分け（方向転換を遅く／速さを下げる、など）までは
  分けていない。


## 寄り道エリア「夜の森」

本編の第7区画ではない。第3区画「マンモスの谷」で1頭倒すと、谷の北側へ
任意で入れる大型サブエリア。大河の文明へ進む本筋は変えない。

- 昼は静かな森、夜になるとオオカミが3〜5頭現れる
- オオカミにはHPがなく、手持ちたいまつ／たいまつ台／犬の近くから逃げる
- たいまつ台は夜ごとに「夜番の薪置き場」の薪を1こずつ使う
- 暗闇で接近されると死亡ではなく谷側へ追い返され、少し士気が落ちる
- マンモス肉2こを餌場へ置くと、一晩に一度だけ群れとの距離が縮まる
- 3晩餌を食べると「最初の犬」が仲間になる。以後プレイヤーについて歩く
- 犬がマンモスの近くにいると、追い込み／仕留めに小さな補助が入る
- 見張りの鐘を買うと、同時に森へ入ってくる群れが小さくなる

つまり「倒す大型ボス」のマンモスとは逆に、夜の森は
**光で追い払い、餌で距離を縮め、最後は共生する**遊びにしている。


### 夜の森・密度アップ

夜の森は空白を作らず、たいまつの光で「見つかるもの」が増える密度にする。
常設ランドマークは池、洞穴、巨大古木、倒木、岩、茂み、木の実、キノコ・薬草、骨、足跡、石積み、消えた焚き火跡。
背景では鳥と蛍が動き、地上では鹿とウサギが常に横切る。オオカミだけが動く森にはしない。
暗闇の描画は既存システムを使うため、たいまつを増やすほどこれらのオブジェクトが光の中に浮かび、開拓の手応えになる。
