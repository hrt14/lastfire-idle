# 世界水族館 館内グラフィック v5

館内の背景が真っ暗になる不具合を直し、背景と生き物を作り直した。
ゲームロジック、価格、進行条件、セーブ形式には変更なし。

## 直した不具合

### 1. 館内背景がまるごと塗りつぶされていた

`components/Shop.tsx` の「作業場の帯」は、**ワールドの一番上が入口**という
縦積みレイアウトを前提に `y = 0` から `KITCHEN.bottom` までを塗る。

水族館は v4 で 5×4 のグリッドになり、入口（area-0）は下段中央にある。
そのため `KITCHEN.bottom` は 1470（= 入口区画の中）になり、
一方この帯は `rect.y0 === 0` の区画、つまり最上段の area-5 / 6 / 9 / 10 に対して走る。
結果として **x が最上段の4区画ぶん・y が 0〜1470** の矩形が `#102a34` で塗られ、
グリッドのほぼ全域が `drawAquariumHall` の上に被さっていた。

水族館の入口ロビーは区画の中（`drawAquariumHall`）で描くことにして、
この帯は水族館では走らせない。

### 2. 遊園地のグラフィックが館内に重なっていた

水族館は runtime の stage id が `park` なので、
`drawClassicStageGraphicPass` / `drawClassicStageForegroundPass` の
遊園地パス（観覧車・お城・万国旗・風船・並木）が館内にも描かれていた。
`visualTheme === "aquarium"` のときは走らせない。

## 背景（`lib/aquariumTheme.ts`）

展示室を「通路 → 大窓 → 天井」の3層で組み直した。

- **大窓**: 区画の上半分いっぱいの巨大水槽。地域ごとの奥景色に、
  水面から差す光・光の網（コースティクス）・奥を横切る魚影を重ねる。
  縦の方立てを入れて「ただの塗り」に見えないようにしている。
- **通路**: 大窓の光が落ちる床。地域ごとの床インレイと順路。
- **来館者**: 手すりに並んで展示を見ている人。地域が進むほど混む。
- **通路の口**: `lib/aquariumLayout.ts` の順路から、
  前後の展示室へ抜ける向きを求めて開ける。18個の箱ではなく一つの館に見せる。
- **入口区画**: 地域の奥景色ではなくエントランスホール。
  館名は外のファサード（`Shop.tsx`）に大きく出す。
  ロビーの壁には強化枠と発券カウンターが重なるので、看板は置かない。

## 生き物（`lib/aquariumArt.ts`）

- **泳ぐ**: 群れは水槽の端から端へ回遊し、大物はゆっくり往復、
  底生（ドジョウ・カニ・エイなど）は底を進む。尾びれも振る。
  座標を動かすだけなので、止めていたときと描画コストは変わらない。
- **形**: 背びれ・胸びれ・二又の尾を足し、細長い魚は体をくねらせる。
  水槽が小さくても種類が読めることを優先している。
- **泡**: 各水槽に立ちのぼる泡。
- **トンネル水槽**: 通路をくり抜くと水槽の大半が通路になり魚が見えないので、
  水は窓いっぱいに見せ、通路は手前に立つ影として重ねる。

## 描画コスト

館内は 18 区画 × 毎フレームだったので、まずそこを削った。

- 画面に映る区画・水槽だけを描く（ワールド全体ではなくカメラ基準）。
- 展示室の動かない層はオフスクリーンへ焼き、毎フレームは貼るだけにする。
  動く層（光の網・魚影・照明・文字）だけを上に重ねる。
- 魚のリム光は `shadowBlur` をやめ、水の明るさで輪郭線の色を変えるだけにした。

|---|---|

| 変更後 | 31.2 ms |
