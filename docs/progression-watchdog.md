# Progression Watchdog

Working Planet の工程型ステージで、必須建築が資材不足のまま永久停止しないための共通ルール。

## Runtime behavior

- 進行中の必須建築を毎フレーム再評価する。
- 不足している完成資材だけでなく、その資材を作る上流工程まで依存関係を逆算する。
- 建築係・はこび手・荷車・船は、建築に必要な工程を通常の販売・配膳より優先する。
- 建築に必要な完成在庫は自動販売で使い切らない。
- 画面下の目的表示も、通常タスクより建築のボトルネックを優先して案内する。
- 依存関係は固定せず毎フレーム再計算するため、材料が揃った工程は自動的に優先対象から外れる。

例: 公共井戸が `粘土 8/8・土器 0/6` で止まった場合、
`土器 → 窯 → 粘土/薪 → 薪割り → 丸太` の順に供給経路を追い、足りない上流工程へ物流を寄せる。

## Design rule

プレイヤーが物流の詰まりを発見して手作業で救済しなくても、ゲーム自身が「次の必須目標に何が足りないか」を理解し、回復可能な状態を維持する。
