# 世界水族館 v6 ― 施設棟と古代棟（18区画 → 54区画）

18区画だった世界水族館を3倍の54区画にした。
ゲームエンジン、セーブ形式、既存18区画の進行条件は変えていない。

## 1. 館内の作り

9列 × 6行のグリッド。順路はひと筆書きで、54区画すべてを通る。

```
        列0  列1  列2  列3  列4  列5  列6  列7  列8
 行0     33   32   31   30   29   28   27   26   25
 行1     34   35   36   37   20   21   22   23   24
 行2     41   40   39   38   19   18   17   16   15
 行3     42   43   44   45   10   11   12   13   14
 行4     49   48   47   46    9    8    7    6    5
 行5     50   51   52   53    0    1    2    3    4
                            入口
```

- **本館 0〜17**: 現世の世界の海。既存のまま。
- **施設棟 18〜21**: ミュージアムショップ / オーシャンレストラン / 両生類館 / 爬虫類館。
  館の中ほどにある2×2の一角。展示だけの館から「一日いられる施設」へ変わる場所。
- **古代棟 22〜53**: 1区画さかのぼるごとに時代がひとつ古くなる。
  館を大きく一周して、**入口のとなり（3,5）** で 40億年前の海にたどり着く。

最後の区画が入口のとなりに来るのは偶然ではない。
館ぜんぶを歩いてから、いちばん最初の扉の横へ戻ってくる。

## 2. 施設棟

### ミュージアムショップ（18）

大窓のかわりに、壁一面が商品棚（`drawShopWall`）。

- 倉庫（`shop-store-1`）で商品を作り、棚に並べておくと来館者が自分で取ってレジで払う
  （既存の `mode: "shelf"`）
- 棚は倉庫を買うまで開かない。並べるものが無いのに棚だけある状態を作らない
- 品出しスタッフ2人で自動化できる

### オーシャンレストラン（19）

大水槽がそのまま壁になっている席。窓は残したまま、床がテーブルと灯りになる。

- 厨房（`restaurant-kitchen-1/2`）で料理を作り、テーブルへ運ぶ（既存の `mode: "table"`）
- 食べ終わると皿が残る。片づけないと次の客が座れない ―― 展示とは別のリズム
- 単価は観覧の4.2倍。館内でいちばん高い

### 両生類館（20）・爬虫類館（21）

大窓のかわりに、陸と水が半分ずつ入ったケージが4つ並ぶ（`drawTerrariumWall`）。
両生類館は苔と浅瀬、爬虫類館は日光浴の岩と乾いた砂で、同じケージでも中身を変えている。

遊びかたは展示と同じ（観覧券を渡す）。ここで操作を増やさない。

## 4. グラフィックのメリハリ

名前を読まなくても、いまどの棟にいるか分かることを狙った。

| | 本館 | 施設棟 | 古代棟 |
|---|---|---|---|
| 天井 | パネルとレール | パネル | **岩肌**（掘り抜いた洞） |
| 壁 | 大窓（大水槽） | 棚 / ケージ / 大窓＋テーブル | 大窓 |
| 水槽の枠 | 濃紺 | 木と真鍮・緑 | **石と錆びた鉄・真鍮の丸窓** |
| 床 | 地域インレイ | 板張り / テーブルの光 / 落ち葉 | **年表の一本線と、埋め込まれた化石** |

水槽の形も8種増やした（商品ケース、レストランの窓、ケージ、石の額、
真鍮の丸窓、氷の張った窓、浅い水盤、熱水のカラム）。

生きものは45種を新しく描いた。カエル・サンショウウオ・ワニ・ヘビ、
クジラ・イルカ・アシカ・カイギュウ・潜る鳥、モササウルス・首長竜、
アンモナイト・オウムガイ・三葉虫・ウミサソリ・甲冑魚・ウミユリ、
アノマロカリス・オパビニア・ハルキゲニア・ディッキンソニア・
ストロマトライト・原始細胞まで。

背景（大窓の奥）は17の時代を足した。
太陽の光が届かない海（ペルム紀末・生命誕生の海）では、
水面から差す光も光の網も出さない。光源は水槽の中だけになる。

大窓の奥に置く影は、水の明るさから色を決める（`shadeFor`）。
明るい水には濃い影、暗い水には淡い影。どちらでも形が読める。

## 5. バランス

区画が3倍になっても「1区画を開くのに何人ぶん必要か」は本館と変わらない。

- 解放価格: 古代棟は1区画ごと **約1.55倍**（本館は約3倍。32区画あるので倍率を落とす）
- 観覧単価: 施設棟から先は **同じ1.55倍ずつ** 伸ばす（`data/aquarium.ts` の `deepBoost`）
- 次区画が候補に出るまでののべ来館数は `2n²+8n`（旧データの式をそのまま延長。n=53 で 6042人）
- 観覧単価の強化は Lv50 → **Lv64**、券の携帯数 Lv10 → **Lv16**、
  館内シューズ Lv12 → **Lv18**、発券速度 Lv14 → **Lv20**
- 8区画ごとに発券端末、4区画ごとに案内・集金スタッフ、
  8区画ごとに集客設備（タイムトンネル / 化石クリーニング室 /
  古生代ドームシアター / 生命誕生ホール）

## 6. 描画コスト

区画が3倍になったので、まず**判定のコスト**を削った。

`state.unlocked` は配列で、`includes` が線形に走る。
区画54・展示162まで伸びると、1フレームのあいだに何万回も文字列を突き合わせ、
描画ではなくこの判定だけでフレームが埋まっていた。
`lib/shop.ts` に `isUnlocked` を足し、配列の長さが変わったときにだけ
Set を作り直すようにした（`unlocked` は積むだけなので、これで足りる）。

このリポジトリの計測環境（ソフトウェア描画のヘッドレス Chromium）での1フレーム:

| | 変更前 | 変更後 |
|---|---|---|
| 18区画・昼 | 60.3 ms | **45.5 ms** |
| 54区画・昼 | 92.3 ms | **52.9 ms** |
| 54区画・夜 | — | 68.1 ms |

54区画になっても、変更前の18区画より軽い。

```bash
npm run dev
CHROME_PATH=/opt/pw-browsers/chromium npx tsx tools/bench-aquarium.ts          # 昼・54区画
CHROME_PATH=/opt/pw-browsers/chromium LAST_AREA=17 npx tsx tools/bench-aquarium.ts
CHROME_PATH=/opt/pw-browsers/chromium PLAY_TIME=420 npx tsx tools/bench-aquarium.ts  # 夜

npx tsx tools/shot-aquarium.ts                       # 場面ごとの見た目
AREAS=18,19,20,21,53 npx tsx tools/shot-aquarium-halls.ts   # 区画ごとの見た目
npx tsx tools/smoke-stages.ts                        # 全ステージが開くか
```

`tools/shot-aquarium-halls.ts` は入口からその区画まで歩き直してから撮るので、
何枚撮っても位置がずれない。`HOLD_FACTOR` で歩く時間の倍率を調整できる。

## 7. さわっていないもの

- セーブ形式（`unlocked` に id を積むだけ。既存セーブはそのまま続けられる）
- 本館18区画の価格・解放条件・展示の中身
- ほかのステージ（`isUnlocked` は同じ結果を返す置き換えで、
  `tools/smoke-stages.ts` で5ステージすべてがエラーなく開くことを確認済み）
