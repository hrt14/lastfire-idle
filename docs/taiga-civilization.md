## 0. 実装メモ（この仕様をどう作ったか）

この仕様書のうち、実際に遊べる形になっているものと、既存のエンジンへの
のせかたを残しておく。ステージ本体は `data/stages.ts` の `taiga`。

### 既存のしくみへの当てはめ

| 仕様のことば | 実装 |
|---|---|
| 畑 | 「水1こ + 種1こ → 穀物1こ」の作業場（`takes: water` / `fuel: seed`） |
| 水くみ場 | 川べりの水がめに水がたまる作業場。かめの水位と%で見せる |
| 取水口 | 人の要らない水の作業場。水汲みの手運びから抜ける |
| 水路・分岐水路 | 作業場どうしの直結設備（`link`）。取水口 → 各畑へ水が流れる |
| 貯水池 | 取水口にためられる数を増やす設備（`capacity`） |
| 石臼 | 人の手が要る加工場（穀物 → 粉） |
| 窯・パン窯 | 薪を燃やす加工場（粘土＋薪 → 土器／粉＋薪 → パン） |
| 牧草地 | 人の手が要る採取場（草） |
| ヤギ・羊の囲い | 草＋水を食べて、乳／毛を出す作業場 |
| 船着き場・中央市場・町の建物 | 建築予定地（`needs` に材料を運びこむと建つ） |
| 市場・交易 | 品ごとに欲しがるものが違う席（干し魚・土器・毛・パン） |

作物の育ちぐあい・水切れ・種切れは、畑の絵そのものに出る（芽 → 苗 → 穂、
土の色、「水がない」「種がない」）。水くみ場も同じで、かめの水位が上がり、
たまったぶんは岸にかめが並ぶ。

### 買う枠の出しかた

遊びはじめから「水がめ24粒・農民48粒・はこび手64粒・2席目76粒・2面目の畑150粒」の
5つが見えている（`revealLimit: 5` と `revealBurst: 3`）。
いちばん安い水がめは3回ぶん運べば買えるので、
最初の1分で「何のために稼ぐのか」が分かる。

そのあとも、買って枠が空くと次の枠が出て、つねに5つ先まで見えている。
第2区画からは6〜7つに増える。

### 区画

6区画すべて入っている。

| 区画 | 中身 |
|---|---|
| 第1区画 川辺の畑 | 水くみ・種・畑2面・食事場3席・農民・はこび手・荷車 |
（第1区画では、水くみと種まきに担当を置かない。最初に雇うのは運ぶ人）
| 第2区画 水路の村 | 取水口・畑3面・水路4本・貯水池・水門番 |
| 第3区画 土と火の工房 | 粘土穴・窯・石臼・パン窯・林・薪割り場・とい4本 |
| 第4区画 牧草地 | 牧草地・ヤギ・羊・家畜用水路・草の運び道 |
| 第5区画 大河の市場 | 川の瀬・干し場・船着き場・中央市場・商人・道 |
| 第6区画 川の町 | 大型穀物庫・公共井戸・記念塔・大型交易船（ここで終わり） |

### この版で入れていないもの

- 季節（春・夏・雨季・収穫期・乾季）と、増水・洪水（§3.4 / §3.5）
- 水門の優先度（高・標準・低・停止）。いまの水路は等分に流れる
- 人口を職業へ配分する画面（§10.4）。人はいまも1人ずつ雇う
- 船が川の上を動く表現。船着き場は建物として建つところまで

季節と洪水は、畑の育ちと水量に効く仕組みなので、
第1〜第2区画の数字が固まってから入れるほうが安全と判断した。

## 1. ステージの位置づけ

「火のはじまり」では、狩猟採集から定住、村の形成、川への進出までを扱う。

「大河の文明」では、川の周辺へ移住した人々が、農業、水路、家畜、土器、交易を
発展させ、村を町へ成長させる。

中心となる変化は以下のとおり。

- 狩って得る生産から、育てて得る生産へ移る
- その場で消費する生活から、余剰を蓄える経済へ移る
- 人が運ぶ物流から、水路と船を使う物流へ進む
- 一つの集落内で完結する生産から、他集落との交易へ進む
- 人員を購入するだけでなく、人口を職業へ配分する
- 川の水量、季節、収穫時期に合わせて設備を組み替える

---

## 2. 目指す体験

プレイヤーは川辺の小さな野営地から始める。

最初は川から水をくみ、手で畑へ運び、種をまき、作物を収穫する。

その後、農民、水汲み、水路掘り、陶工、牧畜係、船頭、商人を増やし、
次の仕組みを順番に作る。

1. 川から水を運ぶ
2. 畑へ種をまく
3. 作物を育てる
4. 収穫物を運ぶ
5. 倉庫へ保存する
6. 穀物を加工する
7. 家畜を育てる
8. 土器を作る
9. 船で大量輸送する
10. 市場で交易する
11. 村を町へ発展させる

ステージ終盤では、プレイヤーが直接水や作物を運ばなくても、水路、農民、倉庫、
工房、船、市場が連携して動き続ける状態を作る。

## 3. 新しい中核要素

### 3.1 農業

農業は、投入後すぐに完成品が出る加工設備とは異なる。次の工程を持つ。

```
畑を耕す
  ↓
種をまく
  ↓
水を与える
  ↓
時間経過で成長する
  ↓
収穫する
  ↓
倉庫または加工場へ運ぶ
```

作物は、成長途中の見た目が変化する。

- 何もない土
- 芽
- 若い苗
- 成長した作物
- 収穫可能
- 収穫後の畑

### 3.2 水

水は通貨ではなく、生産に必要な資源として扱う。用途は複数存在する。

- 畑
- 人口の生活用水
- 家畜
- 土器作り
- 一部の加工
- 火災対策
- 将来の公衆設備

川から得た水を、どこへ優先的に配るかが重要になる。

### 3.3 水路

最初は水瓶を使って水を運ぶ。水路を作ると、水を自動で畑へ送れる。

水路には次の要素を持たせる。

- 取水口
- 主水路
- 分岐水路
- 水門
- 貯水池
- 畑の給水口
- 排水路

水は上流から下流へ流れる。上流の畑へ多く流すと、下流へ届く量が減る。
プレイヤーは水門を使って分配量を調整できる。

### 3.4 季節

ステージには短い季節サイクルを導入する。仮構成：

| 季節 | 主な特徴 |
|---|---|
| 春 | 種まきに適する |
| 夏 | 作物が速く育つが、水を多く消費する |
| 雨季 | 川が増水し、水が豊富になる |
| 収穫期 | 作物が一斉に収穫可能になる |
| 乾季 | 水量が減り、水路管理が重要になる |

1サイクルは10〜15分程度を仮値とする。

季節は失敗を強制するものではなく、生産計画を変える要素として使う。

### 3.5 増水と洪水

雨季には川の水位が上がる。対策がない場合、川沿いの一部施設が一時的に停止する。

影響例：

- 畑が浸水する
- 倉庫への移動経路が使いにくくなる
- 陸上スタッフの移動速度が落ちる
- 水路があふれる

一方で、洪水後の泥は畑を肥沃にする。
洪水は単なる罰ではなく、次の収穫量を増やす機会でもある。

購入可能な対策：

- 土手
- 高床式倉庫
- 排水路
- 水門
- 洪水用貯水池
- 高い船着き場

## 5. 第1区画「川辺の畑」

### 5.1 目的

農業の基本工程を覚える。最初から水路を使わせず、手で水を運ぶところから始める。

### 5.2 初期配置

- 川
- 小さな畑1面
- 種置き場
- 水汲み場所
- 水瓶
- 簡易倉庫
- 住民用の食事場所

### 5.3 最初の体験

1. 川へ近づき水を汲む
2. 畑へ水を運ぶ
3. 種をまく
4. 作物が成長する
5. 収穫する
6. 穀物を倉庫へ運ぶ
7. 穀物を住民へ提供する
8. 報酬を受け取る

最初の収穫までは60〜90秒程度を目標とする。

### 5.4 初期作物

最初の作物は、成長が分かりやすい穀物とする。仮名称：

- 古代小麦
- 大麦
- 雑穀

最初は1種類だけを使う。

### 5.5 購入候補

チュートリアル終了後は、通常6〜8個の購入候補を表示する。

- 農民
- 水汲み
- 2面目の畑
- 種入れ
- 水瓶拡張
- 穀物倉庫
- 収穫かご
- 移動速度強化

## 6. 第2区画「水路の村」

### 6.1 目的

手運びしていた水を、設備によって自動供給する。

### 6.2 基本工程

```
川
 ↓
取水口
 ↓
主水路
 ↓
水門
 ↓
分岐水路
 ↓
畑
```

### 6.3 水路建設

水路は購入した瞬間に完成しない。次の工程を持つ。

1. 建設地点を選ぶ
2. 土を掘る
3. 石で側面を固める
4. 水門を設置する
5. 川と接続する
6. 水が実際に流れる

完成前後で地形が明確に変化する。

### 6.4 水門

水門では、畑ごとに水の優先度を設定できる。

- 高
- 標準
- 低
- 停止

完全な数値入力ではなく、スマホで操作しやすい段階式とする。

### 6.5 水不足

水が足りない畑は、次の状態になる。

- 成長が遅くなる
- 葉が少し下がる
- 地面が乾く
- 水不足アイコンが出る

作物が即座に消滅する仕様にはしない。

### 6.6 購入候補

- 取水口
- 水路掘り
- 水門番
- 貯水池
- 分岐水路
- 3面目の畑
- 4面目の畑
- 水路補強
- 大型水瓶
- 水路清掃係

## 7. 第3区画「土と火の工房」

### 7.1 目的

農業で得た大量の穀物を保存し、加工する。
土器を作り、保存容量と水運搬量を増やす。

### 7.2 粘土工程

```
川岸で粘土を掘る
 ↓
粘土置き場へ運ぶ
 ↓
水を加えてこねる
 ↓
土器の形を作る
 ↓
乾燥させる
 ↓
窯で焼く
 ↓
土器完成
```

### 7.3 土器の用途

- 水運搬量を増やす
- 穀物倉庫の容量を増やす
- 食料の保存期間を延ばす
- 家畜の餌入れに使う
- 市場で交易品として売る
- 酒や油の容器に使う

### 7.4 グラフィック

土器は完成までに形を変える。

- 粘土の塊
- 成形途中
- 乾燥中の灰色い器
- 窯の中で赤く焼ける
- 模様入りの完成品

窯は、たき火や燻製小屋とは別の形にする。必須要素：

- 土や石で作った丸い窯
- 正面の投入口
- 上部から出る煙
- 焼成中の赤い光
- 横に積まれた薪
- 完成した土器棚

### 7.5 穀物加工

追加する設備：

- 乾燥場
- 石臼
- 製粉所
- パン窯
- 粥の大鍋

加工例：

```
穀物
 ↓
石臼
 ↓
粉
 ↓
パン窯
 ↓
パン
```

### 7.6 購入候補

- 粘土掘り
- 陶工
- 土器乾燥棚
- 窯
- 窯の火の番
- 石臼
- 製粉係
- パン窯
- 穀物倉庫拡張
- 高床式倉庫

## 8. 第4区画「牧草地」

### 8.1 目的

野生動物を狩る生活から、動物を飼育する生活へ進む。

### 8.2 初期家畜

最初はヤギまたは羊を導入する。家畜ごとの役割：

| 家畜 | 得られるもの |
|---|---|
| ヤギ | 乳、肉、皮 |
| 羊 | 毛、乳、肉 |
| 牛 | 乳、肉、労働力 |
| 鶏 | 卵、肉 |

最初から全種類は出さない。

### 8.3 飼育工程

```
草または穀物
 ↓
餌場
 ↓
家畜が食べる
 ↓
時間経過
 ↓
乳・卵・毛・肥料
```

### 8.4 家畜の状態

- 空腹
- 満腹
- 水不足
- 休息中
- 生産可能
- 子どもが生まれる

死亡や残酷な表現を主要なペナルティにはしない。
世話が不足した場合は、生産量と繁殖速度が下がる。

### 8.5 肥料

家畜から肥料を得られる。肥料を畑へ使うと、次の収穫量が増える。
これにより、農業と牧畜が循環する。

```
畑の穀物
 ↓
家畜の餌
 ↓
肥料
 ↓
畑の収穫量増加
```

### 8.6 購入候補

- ヤギの囲い
- 羊の囲い
- 牧畜係
- 餌倉庫
- 水飲み場
- 搾乳係
- 毛刈り係
- 肥料置き場
- 家畜用水路
- 大型牧草地

## 9. 第5区画「大河の市場」

### 9.1 目的

余剰生産物を他の集落へ運び、必要な資源と交換する。

### 9.2 川の物流

船は陸上運搬より大量に運べる。ただし、船着き場間しか移動できない。

| 船 | 特徴 |
|---|---|
| 小舟 | 少量、高速 |
| 漁船 | 魚を取れる |
| 運搬船 | 大量の資源を運べる |
| 交易船 | 遠方の集落へ行ける |

### 9.3 港

港には次の設備を置く。

- 船着き場
- 荷下ろし場所
- 川辺の倉庫
- 積み込み係
- 船頭の待機場所
- 市場への運搬路

### 9.4 市場

市場には複数の露店を設置できる。販売・交易品：

- 穀物
- パン
- 土器
- 乳製品
- 毛織物
- 干し魚
- 道具
- 酒
- 油

交易相手によって欲しい商品が変わる。例：

- 山の集落：穀物を欲しがる
- 漁村：土器と毛織物を欲しがる
- 石の集落：食料と交換で石材を出す
- 遠方の町：加工品を高く買う

### 9.5 交易価格

価格は完全なランダムにはしない。

- 基本価格
- 相手集落の需要
- 在庫量
- 季節
- 品質
- 加工度

によって変動する。短時間で極端に上下する投機ゲームにはしない。

### 9.6 商人

商人は市場の商品を選び、船へ積み、交易を行う。後半には交易方針を設定できる。

- 余剰分だけ売る
- 指定量を残して売る
- 特定の商品を優先する
- 指定資源と交換する

### 9.7 購入候補

- 小舟
- 漁船
- 運搬船
- 船頭
- 積み込み係
- 川辺の倉庫
- 市場
- 商人
- 露店
- 交易倉庫
- 船着き場拡張
- 大型交易船

## 10. 第6区画「川の町」

### 10.1 目的

複数の生産区画、港、市場、住宅をまとめ、村を町へ発展させる。

### 10.2 町の区画

- 農業区
- 工房区
- 牧畜区
- 港
- 市場
- 倉庫区
- 住宅区
- 公共施設区

プレイヤーが建物を自由配置する都市建設ゲームにはしない。
基本配置は用意し、購入によって各区画が完成していく方式とする。

### 10.3 公共設備

追加設備：

- 大型穀物庫
- 中央市場
- 公共井戸
- 大水門
- 道路
- 橋
- 集会所
- 神殿または記念塔
- 防洪堤
- 港湾倉庫

### 10.4 人口と職業配分

人口を複数の職業へ配分する。主な職業：

- 農民
- 水路係
- 陶工
- パン職人
- 牧畜係
- 漁師
- 船頭
- 商人
- 建築係
- 倉庫番
- 水門番
- 道路係

人口をすべて生産へ割り当てると、運搬や生活維持が不足する。
生産、物流、生活、建築のバランスを取る。

### 10.5 町の完成条件

仮条件：

- 人口80人以上
- 畑8面以上
- 大水路完成
- 穀物倉庫完成
- 土器工房完成
- 牧草地完成
- 港完成
- 中央市場完成
- 3つ以上の集落と交易
- 3季節連続で食料不足なし
- 洪水被害を一定以下に抑える

## 11. 最終イベント

町の完成後、大河の上流から新しい文明の使者が現れる。
使者は、さらに大きな都市と技術の存在を伝える。

最終イベント案：

1. 大型交易船が町へ到着する
2. 見たことのない装飾と商品が下ろされる
3. 市場へ住民が集まる
4. 使者が地図を広げる
5. 遠方に大きな都市が表示される
6. 町の代表団を編成する
7. 大型交易船で出発する

## 12. 購入候補の共通ルール

### 12.1 表示数

通常時の購入候補は5〜10個とする。

- 推奨：6〜8個
- 最少：5個
- 最大：10個
- 新規追加：一度に最大2個
- 購入済み：枠から消える
- 解放済み未購入：購入まで残る

### 12.2 内訳

| 分類 | 表示数の目安 |
|---|---|
| 人員 | 2〜4個 |
| 設備 | 2〜4個 |
| 強化 | 1〜3個 |

### 12.3 価格帯

- すぐ買える：1〜2個
- 30〜60秒で買える：2〜3個
- 1〜2分で買える：1〜2個
- 長期目標：最大1個

### 12.4 おすすめ

現在のボトルネックに応じ、1個におすすめを表示する。例：

- 畑が乾燥：水路または水汲み
- 収穫物が滞留：はこび手または倉庫
- 水路の下流に水がない：水門
- 穀物が余っている：石臼または市場
- 家畜の餌不足：畑または餌倉庫
- 港に荷物が滞留：船または積み込み係
- 市場の商品不足：生産設備
- 洪水被害が大きい：土手または排水路

おすすめ以外も購入できる。

## 16. ビジュアル方針

### 16.1 川

- 水面が流れる
- 岸辺で波が動く
- 浮遊物が流れる
- 雨季は水位が上がる
- 乾季は岸が広がる
- 船が実際に移動する
- 水路へ水が分岐する

### 16.2 畑

- 畑ごとに水分状態が見える
- 土の色が変化する
- 作物が段階的に成長する
- 収穫時に穂が揺れる
- 収穫後は刈り跡が残る

### 16.3 町の発展

開始時：川、小さな畑、数個のテント。

中盤：水路、工房、牧草地、船着き場、市場。

終盤：大型倉庫、石造りの水門、中央市場、港、道路、橋、多数の住居、
大型公共施設。

発展が遠景からでも分かるようにする。

## 19. 放置収入

放置計算では、単純な最大生産量だけを使わない。次のボトルネックを考慮する。

- 水量
- 畑数
- 成長時間
- 収穫人員
- 倉庫容量
- 加工速度
- 家畜の餌
- 船の運航間隔
- 市場需要

放置中の損失には上限を設ける。

- 船の空荷率
- 交易品の売れ残り率
- 洪水による停止時間
- 季節ごとの売上と生産量

## 21. 受け入れ条件

### 21.1 農業

- 種まき、水やり、成長、収穫が別工程として見える
- 作物が段階的に見た目を変える
- 水不足で成長が遅くなる
- 農民が作業を自動化できる

### 21.2 水路

- 川から水路へ水が実際に流れる
- 水門で分配優先度を変えられる
- 上流と下流の水量が連動する
- 貯水池が乾季の水不足を緩和する

### 21.3 土器

- 粘土から土器までの工程が見える
- 完成した土器が運搬量または保存量へ影響する
- 窯が他の火設備と異なる見た目を持つ

### 21.4 牧畜

- 家畜が餌と水を消費する
- 世話の状態が見た目で分かる
- 乳、毛、卵、肥料など複数資源を生産する
- 肥料が農業へ戻る循環が成立する

### 21.5 船と交易

- 船が川の上を実際に移動する
- 船へ荷物を積み下ろしできる
- 交易相手によって需要が異なる
- 商人によって交易を自動化できる

### 21.6 季節と洪水

- 季節によって川と畑の見た目が変わる
- 雨季と乾季で水量が変化する
- 洪水対策設備に意味がある
- 洪水後の肥沃化による利点がある

### 21.7 購入候補

- 通常5〜10個を表示する
- 人員、設備、強化が混在する
- 購入順によって進行不能にならない
- おすすめは表示するが、購入を強制しない

### 21.8 ビジュアル

- 職業ごとに道具、シルエット、動作が異なる
- 新設備購入後、マップ上の景色が変化する
- 川、水路、畑、工房、牧草地、港、市場を名称なしでも判別できる
- 村から町への発展がマップ全体から分かる
