## 0. このステージだけ、横三列の縦スクロール

これまでのステージは、区画を右へ右へと足していく **横スクロール**だった。
このステージは **横に三列を並べたまま、下へ下へ**進む。

```
        左の列          中の列            右の列
        掘る・採る      火にかける        渡す
        ────────────    ────────────      ────────────
 段1    銅の露天掘り ─▶ 石の炉        ─▶  谷の市
 段2    尾根の木立   ─▶ 溶解炉・鋳込み ─▶ 尾根の市
 段3    隊商宿       ─▶ 合わせ炉・研ぎ ─▶ 隊商の刃物市
 段4    工房の粘土場 ─▶ 鐘・鏡        ─▶  祭主・貴人
 段5    王領の坑道   ─▶ 冠の細工場    ─▶  王の受け取り
 段6    神殿の石切り ─▶ 神殿の大炉    ─▶  神殿の供物台
                                          ＋ 大鼎
```

一段（区画）が、スマホの画面ちょうど1枚。
手前の段でひととおり回せるようになったら、下の段をひらく。

**なぜ縦にしたか。** 工程が横に長くなると、
「いま何がどこで詰まっているか」を見るのに横スクロールが要る。
三列に固定すると、
**素材が足りないのか、火が止まっているのか、渡す先が無いのか**が、
画面を動かさずに左右の位置で分かる。

### 実装

| 仕様のことば | 実装 |
|---|---|
| 横三列 | `StageDef.columns = 3`。列の中心は x = 70 / 210 / 350 |
| 画面に三列ぜんぶ入る | `view = 440`（世界の横幅は 420） |
| 段 | `AreaSpec.rect` を y だけずらして積む（一段 560、最後の段だけ 720） |
| 段のなかの行 | 上から 80 / 200 / 320 / 440。雇う枠・設備の枠は作業場の +52 |
| 客の出入り | 通りが遠すぎるので、客はその段のはずれに現れて、そこへ帰る（`columnMode`） |
| 行列 | 作らない。席が空くまで人を出さない（並んでも席まで歩けないため） |

エンジンで変わるのはこの3点だけ。
描画・買い物・自動化・放置計算は、これまでのステージとまったく同じものを使う。

## 2. 配合 ―― このステージの新しさ

銅は谷で採れる。錫は **隊商でしか来ない**。

`lib/bronze.ts` は、いま吹いた **精銅の数** と、届いた **錫の数** を
直近 240 個ぶんの窓で数えていて、その割合で青銅の質が決まる。

| 錫の割合 | 質 | 器の値 |
|---|---|---|
| 3% 未満 | 赤がね | ×0.85 |
| 3〜7% | 並の青銅 | ×1.0 |
| **7〜20%** | **良い青銅** | **×1.4** |
| 20〜32% | 錫勝ちの青銅 | ×1.1 |
| 32% 以上 | もろい青銅 | ×0.85 |

いちばん強いのは、銅九に錫一のあたり（実際の青銅もこの割合）。

- **たくさん掘るだけでは値が上がらない。** 掘り場を足すと錫が薄まって質が落ちる
- **錫だけ増やしてもだめ。** 精銅を増やして薄める側の手も要る
- どちらの端でも 0.85 までしか下がらない ―― 配合で詰ませない
- **隊商宿を買うまでは「銅」のまま、倍率 1.0。**
  区画を開けただけで質が落ちる、をやらない ―― 錫を取りに行くと決めたときから配合が始まる
- 合わせ炉は精銅2〜3に錫1で食うが、精銅は市でも売れる。
  だから普通に回すと錫は 10〜18% あたりに落ちつく ―― 良い配合の帯のなか。
  隊商だけを伸ばすと 20% を越えて、かえって値が下がる

HUDには「錫 12%」ではなく **「良い青銅」** と、
次にどうすればいいかの一言（「錫が足りない ― 隊商宿と錫の運び手を増やそう」）を出す。

## 3. 王の名簿（位）

納めた器の重みが積みあがると、王の名簿で位が上がる。

| 重み | しなもの |
|---|---|
| 1 | 青銅の刃 |
| 3 | 銅鐸 |
| 5 | 銅鏡 |
| 12 | 王の冠 |

| 位 | 何が変わったか | 効き目 | 献上 |
|---|---|---|---|
| 0 谷の掘り手 | まだ王は、この谷を知らない | ― | 0 |
| 1 里の鋳手 | 谷の炉が里に知られた | 作業場 +8% | 12 |
| 2 王の使いが来る | 使いが器を取りに来る | 集まり 1.25倍 | 70 |
| 3 宮の匠 | 宮の名簿に名が載った | 受け持ちのある作業場 +18% | 300 |
| 4 国の鋳師 | 国じゅうの型が集まる | 単価 1.3倍 | 1,200 |
| 5 王家の宝師 | 王家の宝を任される | 全体 +12%・集まり 1.4倍 | 4,500 |
| 6 大鼎の名匠 | 大鼎を鋳るゆるしを得た | 全体 +20%・単価 1.4倍 | 16,000 |

位は献上の数だけでなく、**区画の進み**もそろわないと上がらない
（`Rank.needs`）。工房と国が、いっしょに育つ。

**単価 ＝ 基本単価 × 位の倍率 × 配合の質。**
どちらか片方だけ伸ばしても、途中で頭打ちになる。

## 4. 区画

| # | 名前 | 値段 | 開く条件 |
|---|---|---|---|
| 1 | 銅の谷 | 0 | ― |
| 2 | 炭焼きの尾根 | 2,600 | 一度でも器を打つ（`mark-first-cast`） |
| 3 | 錫の隊商路 | 44,000 | 屋根つきの鍛冶場が建つ |
| 4 | 鋳物の工房街 | 600,000 | 隊商の宿場が建つ |
| 5 | 王の宮 | 9,000,000 | 大鋳物場が建つ |
| 6 | 大鼎の神殿 | 220,000,000 | 王の鋳物殿が建つ |

区画の条件を「お金だけ」にしていないのは、
**その段の流れを一度は回してからでないと、次の段が開かない**ようにするため。

### 締め

第6区画の **大鼎**。石段の壇を組んでからでないと鋳ることさえできず、
荒鋳物30・鋳型24・石20・冠6 ―― 三列ぜんぶの流れがそろって、はじめて立つ。

> 人は、土から金属を取り出して形にできるようになった。

## 5. 点検

| 道具 | 何を見るか |
|---|---|
| `tools/check-bronze.ts` | id の重複・`unlockAfter` の指す先・作れない材料・行き止まりの品・**三列からのはみ出し**・**枠の重なり** |
| `tools/reach-bronze.ts` | お金を無くした状態で通しで動かし、どの作業場も物を出すか・建物がぜんぶ建つか・大鼎まで行けるか |

```
npx tsx tools/check-bronze.ts
ALL=1 npx tsx tools/reach-bronze.ts 25
```

三列のレイアウトは、座標を一つずらすだけで枠が重なって押せなくなる。
`check-bronze` の「枠が重なっている」は、そのための見張り。
