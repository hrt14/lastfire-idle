# 「湯けむり温泉街」仕様書 v0.2

- シリーズ：はんじょうダッシュ（ラーメン一直線 → ドリームパーク → **湯けむり温泉街**）
- ステージ種別：独立した第3ステージ
- **実装ずみ。** 入れたときに変えたところと、測った数字は §10・§11
- モチーフ：日本の山あいの温泉街（草津温泉の街のかたち）。
  固有名詞・実在の店や施設の名前・案内図のトレースは使わない（§2）

一本の道からはじめて、歩いて楽しい温泉街をつくる。

**このステージは店の中からはじまらない。** 最初の画面にあるのは、
山あいの道と、こわれかけの足湯と、手ぬぐいの箱だけ。
道の両側に店を建て、道を延ばし、また店を建てて、町を大きくしていく。

## 2. 草津温泉から取り入れたもの・取り入れないもの

**取り入れる（かたちと体験）**

- 高いところから坂を下って、街の中心にある源泉の広場へ出る構造
- 中央の、湯気を上げる大きな源泉施設と、そこから引いた木の樋
- 源泉広場を囲む浴場・食事処・土産店・宿
- 中心から横へ伸びる食べ歩きの通り、その先の温泉が流れる川と露天風呂
- 裏路地の小さな湯（手湯・顔湯）と甘味店
- 石段の先の高台にある社と展望
- 石畳・瓦屋根・格子戸・提灯・のれん・湯けむり

**取り入れない**

- 「草津」の地名、実在する旅館・店舗・浴場・通りの名前
- 実在の店の外観や看板、マスコット、案内図のトレース
- 特徴的な建物を、同じ位置・同じ形で置くこと
- 実在の歌・掛け声・ロゴ

地図は回転させ、距離を詰め、道の角度と源泉の形を変えてある。
湯もみは動作の名前として使い、演目そのものは架空の「湯もみ小屋」とする。

## 3. ワールドの作り

ワールドは **横 2,700 × 縦 1,600**（ワールド単位）。
道も建物も人も、同じ座標のうえに同じ縮尺で置く。画面はカメラで追う（`view: 440`）。

区画は2種類ある。

| 種類 | 実装 | ふるまい |
|---|---|---|
| **道**（10区画） | `building` なし | 壁がない。足湯・屋台・強化の枠が出る。石畳を敷く |
| **建物**（20区画） | `building` あり | 四方が壁。道に面した一辺に戸口がひとつ開く |

**いちばん下（南）が温泉街の入口**で、そこから北へ町が伸びていく。
入口道路より下に区画を置かないので、客が歩いてくる通りの位置は最後まで動かない。

### 3.1 道のネットワーク

**客も店員も、道づたいにしか歩けない。** 建物は壁でふさがっているので、
まっすぐ突っ切ることはできない。経路は次の点と穴でできたグラフを幅優先で解く。

- 点：棟（建物）・通り（道の区画）・外（客が来る道）
- 穴：戸口（棟 ↔ 面している通り）・辻（通り ↔ 通り、接している辺の重なり）・
  町の入口（いちばん手前の通り ↔ 外）

道を買うと辻が増え、町の奥までの道すじが短くなる。
新しい道を買うまで、その先の店には**遠回りしてしか行けない**。

### 3.2 建物の中

建物を買うと、外側（壁・戸口・床）だけが建つ。
**中の作業場・席・棚・帳場・店員は、そこから一つずつ買っていく。**
店員は担当の店から出ない（`shop` の番号で分ける）ので、
店を建てるたびに、その店のなかだけで人手のやりくりが起きる。

## 4. はじめの10分

ゲームを開けたときにあるのは、入口道路・手ぬぐい箱・足湯2つ・工事柵だけ。

1. 手ぬぐい箱から手ぬぐいを拾う
2. 足湯で待っている客に近づくと、自動で渡す
3. 客が置いた料金を踏んで回収する（60円）
4. 3人ぶんで **腰かけ足湯（120円）** が建つ
5. 屋根つき足湯（340円）、手ぬぐい係（460円）、湯かご（強化）と続く
6. **蒸しまんじゅう屋（1,200円）** ― 最初の建物。蒸し器を置き、店先の棚に並べ、
   帳場のレジ係を雇うと、客が自分で取って払っていくようになる
7. その先に **到着広場（2,900円）** が見えて、町が横に伸びはじめる

同時に見せる枠は最初4つ（`revealLimit: 4`）。
町が広がると6〜8つに増え、「浴場を建てるか、通りを延ばすか、宿を建てるか」を選べるようになる。

## 6. 店ごとの遊び

運ぶものは3種類。どれも「作る → 運ぶ → 渡す → お金」で、渡し方だけが違う。

| 商品 | 作る場所 | 渡す場所 | 客のふるまい |
|---|---|---|---|
| **手ぬぐい・湯かご**（main） | 手ぬぐい箱・湯汲み場・湯札の受付 | 足湯・浴槽・見物席 | 受け取って湯に入り、料金を置いて帰る |
| **料理**（food） | 厨房・焼き台・板場 | 食事処の卓・旅館の客室 | 食べ終わると器が残る。片づけるまで次が来ない |
| **甘味・みやげ**（goods） | 蒸し器・仕込み場・倉庫 | 店先の棚・ショーケース | 自分で取って、帳場へ払いに行く |

- **足湯**（道の上）― 手ぬぐい係と集金係。町のどの通りにも置ける
- **共同浴場・大露天風呂** ― 湯札の受付 → 檜の内湯・岩の湯・打たせ湯。
  大きい湯船は手ぬぐいを2枚・3枚まとめて要るので、湯かご（積載）を上げないと運べない
- **食事処**（そば・串焼き・温泉たまご・甘酒・炉端）― 料理人・配膳係・片づけ係
- **甘味とみやげ**（蒸しまんじゅう・ミルクプリン・焼き菓子・夜パフェ・湯の花・木彫り・御守り）
  ― 職人・品出し係・レジ係
- **湯宿**（小・大・大旅館）― 板場の膳を客室へ運ぶ。単価はいちばん高く、
  片づけ（布団係）が追いつかないと次の客が入れない
- **湯もみ小屋** ― 木札を渡すと、板で湯をかき混ぜる演目を見ていく

### 6.1 強化と設備

- 強化（入口道路に4枠）：**湯かご**（持てる数）・**わらじ**（足の速さ）・
  **湯口の手入れ**（作る速さ）・**もてなし**（単価）
- 源泉：湯樋の掃除（全作業場 +30%）・木製分水槽（貯めておける数 +4）・
  湯銭箱（お金が自動で入る）・湯口の拡張・配湯管の増設
- **石畳**（4本）：買った道を通ると足が速くなる。町が広いほど効く
- 集客（かけ算）：のぼり 1.25 → 案内板 1.4 → 湯もみの太鼓 1.6 → 提灯の並木 1.8 →
  浴衣の貸し出し 2.0 → 展望台 2.4 → 湯あかりの灯籠 3.0

## 7. 見た目

Canvas 2Dの図形だけで描く（画像アセットは持たない）。

- **背景**：町の奥に遠い尾根が二重にかかり、そのあいだから湯けむりが上がる。
  きわには杉林。町より下は谷あいの闇
- **道**：石畳。坂には段差の線、石段には段と灯籠、夜見世通りと食べ歩き通りには提灯の列
- **源泉広場**：ゆがんだ楕円の湯だまり、木の湯樋5本（湯が流れて見える）、
  かたわらに湯滝、まわりに石畳と柵

- **湯**：足湯（石組みと腰かけ板）・檜の内湯・岩の湯・打たせ湯・寝湯・手湯／顔湯。
  どれも湯気が立ち、客は肩まで浸かる
- **店先**：蒸籠から湯気の立つまんじゅう、ガラスのショーケース、串の焼き台、
  囲炉裏の炭、温泉たまごのかご、御守りの棚

## 8. エンジンに足したもの

ステージ定義（`data/stages.ts`）だけでは足りず、`lib/shop.ts` に次を足した。

| 足したもの | 何のため |
|---|---|
| `AreaSpec.door.side`（`"s" \| "n" \| "e" \| "w"`） | 道の南側にも北側にも建物を並べるため。戸口を四辺どこにでも開ける |
| 道のノードと辻の穴 | 道の区画を経路の点として扱い、通りづたいに歩かせる |
| `placeOf` のすきま拾い | 区画のすきまに立っても、すぐ横の通りにいることにする |
| 通り抜ける点の選び方 | 穴のはしではなく、幅の1/3内側（狭い戸口はまんなか）を通る。<br>これがないと、戸口を抜けた直後に壁へ向き直って引っかかる |
| `StageDef.requiresStage` | 解禁条件を前ステージ（ドリームパーク）で数える |
| 温泉街の背景・区画の飾り・席／卓／棚の絵（`components/Shop.tsx`） | 見た目 |

解禁条件は **ドリームパークの10区画をぜんぶ開けること**。

## 9. 測りかた

ブラウザなしで `lib/shop.ts` をそのまま回すハーネスを2つ使った。

1. **配置の検査** ― 区画の重なり、席や店員が区画からはみ出していないか、
   買う枠が先に開く区画に乗っているか、戸口の外が道になっているか、
   道がぜんぶつながっているか、担当者と作業場の食い違いがないか
2. **通しの時間** ― 「買えるものは安いものから買う → その形で1分ぶん稼ぐ →
   次のいちばん安いものが買えるまで時計を進める」をくり返す

## 10. 測った数字

| 測ったもの | 実測 |
|---|---:|
| 町を建てきったときの稼ぎ | **約9億円/時**（1.5億円/10分）|
| 提供のレート | 約1.2人/秒（席75）|
| 通しで全部買い切るまで | **約50時間** |
| 街区が開くまで（通し） | 源泉広場 0.2時間 → 食べ歩き 0.8時間 → 裏湯路地 1.7時間 →<br>宿場 2.5時間 → 湯川公園 3.3時間 → 山門 7.2時間 →<br>夜見世 12.5時間 → 大旅館 28時間 |

（ハーネスのプレイヤーは何もしない＝完全放置の値。
実際は自分で運ぶぶん、序盤はこれより速い）

作りながら分かったこと。

- **道のつながりが、そのまま稼ぎになる。** 道をノードにする前は、客が建物の壁に
  ひっかかって町じゅうで立ち往生し、稼ぎがほぼ0になった
- **戸口は「まんなかを通す」必要がある。** 穴のはしを目がけると、抜けた瞬間に
  壁へ向き直ってしまう。ここを直しただけで提供が 33人/30秒 → 84人/30秒 になった
- **値段は稼ぎに合わせて引き直した。** 最初に置いた値段では通しで25,000時間かかった。
  対数のうえで高いところほど強く圧縮し、そのあと全体を持ち上げて50時間に合わせた

## 11. まだ入れていないもの

仕様のうち、今回は入れていない。中核のループ（道→建物→中身→自動化）を
先に通すことを優先した。

| まだのもの | 補足 |
|---|---|
| 昼夜サイクル・夜間売上倍率 | 夜見世通りは「夜の店」という設定と見た目だけ |
| 天候（小雪）と雪かき | |
| 湯量の上限と湯温低下 | いまは湯を運ぶこと自体が制約になっている。<br>源泉の設備（湯口の拡張・配湯管）は貯蔵量として入っている |
| 宿泊客の長い滞在（受付→客室→湯→食事→夜の散策→朝食） | いまの客室は「膳を運んで、食べて、帰る」まで |
| ミニマップ | |
| 建設中のアニメーション（地ならし→石畳→街灯） | いまは買うと建つ |
| 湯あかり大祭とクリア演出 | |
| 客の種類（カップル・家族・団体・常連） | 回遊（一人が何軒もまわる）は既存のしくみで動いている |
